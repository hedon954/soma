## 保留什么，细化什么

保留居中标题、日历、四周期切换、能量主图、紧凑训练 / 身体摘要和四个底部 Tab。
绿色区分饮食与能量，青色表达训练频率，蓝色表达身体测量；预估线使用虚线。

| 范围 | 展示 | 点击后 |
| --- | --- | --- |
| 日 | 当日摄入 / 全天预估、三大营养素、训练记录与分享、当日身体测量 | 进入同一原始记录详情编辑 |
| 周 | 7 天摄入柱与消耗线、训练天数 / 组数、带日期的身体测量 | 先选某天，再点“查看当天” |
| 月 | 自然月每日柱，覆盖天数，训练与身体摘要 | 每一天都可选；缺测日也可进入 |
| 年 | 12 个月，摄入 / 消耗按日均，训练累计 | 选月 → 查看该月 → 选日 |

选中信息分两行：第一行日期与“查看当天 / 该月”，第二行摄入和预估消耗。
图表选点只更新选中信息，不切换范围；进入下级后返回，恢复原范围、选中点与滚动位置。
日历可直接跳到任意历史日，左右箭头切换相邻周期；查看过去时出现“回到今天 / 本周 / 本月 / 本年”。

## 数值规则

- 摄入和训练的小计可显示“已记录 0”，但不能把漏记变为真实零摄入；缺测点保留空缺标识。
- 周 / 月 / 年摄入日均显示记录覆盖天数；年均按天加权，不直接平均不同样本数的月均。
- 有记录不代表记录完整；“记录差值”不是实际热量缺口。全天预估与截至当前的设备统计不得混用。
- 训练天数按日期去重；休息日不画正柱；身体图不补虚构测量。
- 今天或当月未结束时明确标识，不把未来画成 0，也不与完整上一周期直接比较。
- 年稿为“截至 8 月 31 日”的已结束日快照示例；实际当前年应纳入已有当月数据并注明统计截至日。

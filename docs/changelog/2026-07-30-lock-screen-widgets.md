# 2026-07-30：锁屏快速记录

## 用户反馈

现有 Soma Widget 只能添加到主屏幕，无法出现在锁屏组件库，仍然需要先解锁并寻找 App，
没有完全达到低摩擦记录的目标。

## 本轮实现

- 保留原有中尺寸主屏幕 Widget 和三个并列入口；
- 新增文字、拍照、照片/视频三个独立锁屏 Widget；
- 每个锁屏入口支持行内、圆形和矩形三种 `WidgetFamily`；
- 点击继续复用 `soma://capture/{mode}`，打开 Soma 后进入对应的文字、相机或媒体流程；
- 锁屏 Widget 只传递录入意图，不访问 SwiftData、身体数据、媒体内容或 Agent。

## 隐私与交互边界

设备锁定时由 iOS 先完成身份验证，Soma 不绕过系统直接访问相机和照片。锁屏入口与主屏幕
组件、App Shortcuts 共用同一条录入路由，因此没有新增数据写入或同步路径。

## 验证

- Widget Extension 可同时编译主屏幕与三种锁屏组件；
- 真机组件库可发现 Soma 的三个锁屏入口；
- 三种入口分别路由到文字、拍照和照片/视频流程。

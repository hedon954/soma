# 2026-07-30：对话 Session 与发送反馈

## 用户结果

- 教练对话开始按 Session 持久化。重新进入 App 时，今天已有消息就继续当天会话；最后
  消息早于今天时自动进入新会话。
- 教练页只使用当前 Session 作为聊天和 Agent 最近上下文，旧会话可从历史入口回看。
- 发送文字、图片或视频后立即收起键盘、清空输入并滚到消息底部，随后在原位等待 Agent
  的流式回复或错误。
- 开发者设置直接提供执行日志入口；不可操作的“内置工具协议”及相关说明从设置界面移除。

## 数据与兼容

- 新增本地 `ConversationSession`，消息通过可空 `sessionID` 归属会话。
- 旧版消息首次加载时按设备自然日归档，不删除聊天、媒体或 Trace。
- Session 继续遵守演示/个人空间隔离，不增加账户、云同步或远程数据。

## 质量

- 为跨天新建、当天复用、空会话去重、旧消息归档和消息关联增加确定性测试。
- 发送后的键盘与滚动使用 SwiftUI 状态和稳定底部锚点，不使用固定延迟修复竞态。

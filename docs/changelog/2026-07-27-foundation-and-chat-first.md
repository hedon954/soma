# 2026-07-27：从私人健身工具到聊天优先 MVP

## 产品方向

- 确立无账户、本地优先的 iOS 私人 AI 健身教练。
- 覆盖电子健身房、饮食、身体、训练记录和数据统计五个核心问题。
- 支持多个健身房，并允许指定当前健身房。
- 采用 Apple 原生、克制的视觉风格，统计借鉴 GitHub contribution graph。

## 首个可运行闭环

### 教练输入

- 支持文字、图片和视频。
- 接入 iOS 系统语音识别。
- 视频在本机提取关键帧，供多模态模型分析动作。

### 结构化数据

- 建立健身房、器械、健身房媒体、饮食、身体、训练和对话模型。
- 媒体保存到 Application Support 私有目录。
- 远程 AI 默认关闭，API Key 存入 Keychain。

### 演示能力

- 内置虚构训练、饮食、体态和健身房图片。
- 内置演示记录和本地演示分析器，使无 API Key 状态也可验收完整界面。
- 演示数据不代表用户真实数据。

## 信息架构收敛

- 否决“今日、健身房、记录、数据、教练”五栏结构。
- 否决训练、饮食、身体分别手动添加的传统流程。
- 顶层界面收敛为“教练”和“进展”。
- 聊天成为唯一创建入口；列表和详情保留用于审查。

## 进展与记录

- 增加训练、饮食和身体的最近记录列表。
- 增加 GitHub 风格连续性热力图及日期提示。
- 体重趋势支持周、双周、月、季和横向拖动。
- 增加训练容量趋势，与体重趋势同级；按自然日聚合有效记录的 `组数 × 次数 × 重量`。

## 健身房审查

- 健身房详情展示上传图片、环境总结和器械列表。
- 器械列表调整为统一左对齐，修复图标、文字和分隔线中心漂移。
- 移除面向用户的识别置信度百分比，避免把内部不确定性当成有意义的产品指标。

## AI 供应商与分发准备

- 内置 OpenAI、DeepSeek、阿里云百炼、火山引擎和腾讯云。
- 增加 Base URL、API Key 和模型配置。
- 支持调用供应商模型列表、下拉选择和手动模型 ID。
- 增加已知多模态能力提醒和供应商错误的友好展示。
- 占位 Bundle ID 使用 `top.hedon.formcoach`，准备 Automatic Signing、连线真机和 TestFlight 归档脚本。

## 当日被替代的方案

- 独立“新增训练/饮食/身体”表单。
- 顶层五栏导航。
- 器械置信度百分比。
- 居中且宽度不一致的器械列表排版。

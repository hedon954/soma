# 2026-07-29：Soma、身体信息与健康数据闭环

## 聊天体验

- 对话正文改为原生可选择文本，支持长按后拖动选择范围并复制部分句子。
- 移除聊天页左上角的演示/个人切换，入口下沉到高级设置。
- 当前健身房切换移到输入框上方的紧凑菜单；设置保留完整健身房管理。
- 对话解析提升为 App 级任务：用户切到进展或设置后仍继续执行。
- UI 流式显示 Agent 文本和模型、Skill、工具的当前状态。
- 单条消息支持最多十项图片、视频或二者混合选择；全部附件统一保存和分析，三项起在聊天中以微信式牌组折叠，点击后展开为竖直列表，再次点击收起，不提供横向滑动。
- Tool 与 Skill Event 从临时状态升级为对应回复下方的持久时间线，重新进入聊天仍可审查；该过渡呈现于 7 月 30 日进一步修正为有序异构 Event Cards。
- 教练回复改用完整 Markdown 渲染，并收紧为简洁自然、避免过程复述和长表格的表达。
- 新增 Soma 中尺寸主屏幕组件与 App Shortcuts，可从系统入口直接开始文字、拍照或照片/视频记录。
- 聊天冷启动和重新进入时定位到最新消息；媒体快捷入口直接呈现系统选择器，不依赖固定延时。
- 媒体牌组折叠态不再让首图原始比例决定整条消息高度，改为按方向选择稳定画布；展开态仍保留各附件自身比例。

## 身体信息

- 新增身体信息页面。
- 个人档案支持昵称、生理性别、出生日期、身高、参考体重、健身目标和健康备注。
- 以出生年月替代“年龄”，年龄由系统动态计算。
- 个人体态图通过身体记录形成历史列表，可回溯不同日期。
- Agent 收到体态图时可以通过身体记录工具归档。

## 运动热量估算

- 新增第八项 Skill：运动热量估算。
- 使用本地确定性 MET 公式，减少模型自由计算的不稳定性。
- 优先使用用户实际时长和最近体重。
- 无氧训练缺少时长时，可根据组数、次数、明确间歇和动作节奏推算仅用于计算的时长。
- 推算时长不回填实际训练时长，并在记录中保留“时长来自估算”。
- 训练详情显示估算热量、MET、计算时长和依据。

## Apple 健康、Keep 与 COROS

- 接入 Apple 健康只读同步：
  - 体重；
  - 训练；
  - 训练活动能量。
- 外部数据统一转换为 Soma 的身体或训练记录。
- 使用 `HKAnchoredObjectQuery` 按来源和数据流保存增量游标。
- 使用 HealthKit 样本 ID 去重，并同步来源删除。
- Keep 数据在其写入 Apple 健康时可以间接导入；当前不依赖非公开直连。
- COROS 数据优先经 Apple 健康导入；完整云端直连保留到获得合作 OAuth/API 后。

## 设置重组

- 设置首页按频率重排：
  1. 个人与训练；
  2. 服务；
  3. 隐私与高级；
  4. 关于。
- AI 供应商、健康设备、隐私、提示词、Skills、执行日志和演示空间分别下沉到合适层级。
- 减少首屏信息密度，避免把高阶诊断能力暴露给普通用户。

## 品牌迁移

- App 正式更名为 **Soma**。
- 产品主张确定为 **Your body, understood.**
- `FormCoach` 项目、target、module、源码目录、测试、Scheme 和显示文案全部迁移为 `Soma`。
- Bundle ID 从 `top.hedon.formcoach` 改为 `top.hedon.soma`。
- Keychain service、归档脚本和文档同步改名。
- 按用户要求不迁移旧 App 数据。

## 当前边界

- App 内页面切换不会中断 Agent，但系统杀死进程后不保证继续。
- Keep/COROS 不使用未经授权的私有接口。
- 不展示模型 thinking。
- Trace 暂不支持一键重试。
- TestFlight 仍需要付费 Apple Developer Program；免费 Personal Team 可连线安装真机，但签名会过期。

# ADR 0143：训练内容统一按天展开

- 状态：已采纳，已实现
- 日期：2026-10-18
- 上游依据：[PRD 074](../prd/074-composable-training.md)、[训练领域协议](../engineering/training-domain-model.md)（原周期与执行来源）
- 部分替代：[ADR 0140](0140-training-schedule.md)（槽位内容和完成身份；周期缺席规则不变）
- 后续替代：暂无
- 下游落地：[数据库结构](../engineering/database-schema.md)、[验收](../acceptance.md)

## 背景

原计划的每天只保存课程 ID，直接编排动作也必须先建课程，执行和完成判定进一步耦合课程。

## 决策

TrainingContentSource 是动作处方、课程和计划的统一引用值：动作内嵌 TemplateExercisePrescription，课程和计划以 UUID 引用。展开服务将其编译为有序天序；计划保留休息日，前后内容另起一天。所有写入和开始训练都经同一个展开与处方校验服务。

TrainingScheduleSlotValue 增加可选 id 和 contents，存入原 slotsData。旧 course/programID 和 rest 保持可解码；不新增 SwiftData 持久字段或注册模型，不重建用户数据。引用缺失、循环、超过 14 天或没有动作时拒绝写入。

新组合的完成身份是根计划与展开路径生成的稳定 UUID，Session 使用现有 programID 保存来源身份并保存当天名称及处方快照，不生成隐藏 TrainingProgram。旧单课程槽位仍识别原课程完成记录。Session 创建抽取为接受处方与来源身份的共享入口。

推荐读取最近 WorkoutEntry 的有序证据，按逻辑组和左右还原，绝不用聚合代表值重建异构组；只提供目标，不写成训练事实。使用已有参数编辑器确认。

工具在未提交草稿实现上直接改为可组合内容，不为工作区内中间版本保留兼容协议。所有设备与服务器 Schema 同步。

## 未采用

- 自动建隐藏课程：继续把内部结构强加给用户。
- 把多天计划摊成一天：会丢休息日和时间含义。
- 嵌套对象复制成快照：源内容修改不能用于后续训练；只在开始 Session 时冻结。

## 验证

旧 JSON 解码、混合内容与休息展开、直接和间接循环、缺失引用、上限、稳定身份、直接开始快照、异构参数与空值测试；make check 和 make verify。

选择器使用顶部原生分段控件按课程、动作、计划顺序切换，默认课程，固定在列表外；搜索只作用当前列表。保留独立弹层和进入编辑页时加载的候选数据，不在渲染时重建 SwiftData 查询。

## 结果

无需隐藏课程即可执行混合内容。引用更新可能让父计划超限或失效；打开与开始时显示错误，要求用户修改，不自动删除引用。

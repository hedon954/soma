# ADR 0153 · Agent 读取当日日账

- 状态：已采纳
- 日期：2026-11-19
- 上游依据：[PRD 082](../prd/082-coach-progress-reliability.md)、[工程契约](../../CLAUDE.md)
- 下游落地：[Agent Tool 目录](../engineering/agent-tool-catalog.md)

## 背景

进展页和教练需要使用同一时间点的饮食与能量数据。模型可以用这份日账承接需要推理的饮食建议。

## 决策

`get_daily_energy` 是无参数、只读的本机 Agent 工具。每次调用以设备当时的自然日、时区和已保存状态读取进展快照。返回「饮食与能量」的摄入条目、消耗分项、营养指标和目标、差额、剩余额度及缺失状态。进展和工具共同使用同一计算、明细与显示精度。调用后若同一回合保存或更正饮食，可以再次读取最新日账。

这项授权限于本次工具调用和 App 直连用户配置的模型。允许同一请求使用界面已经展示的当日能量归因，包括由 Apple 健康参与估算的能量汇总。结果仅作为当轮模型输入，持久化 Tool 事件与检查点只保留读取标记。应用备份、导出与 Soma Server 继续沿用健康数据边界。后台持续执行的服务会落盘 Tool 结果，因此远程 Job 不注册或执行该工具。日账卡片仍可在设备上直接展示。

## 结果

用虚构数据验收进展与工具分项一致、缺失状态、同轮写入后再次读取、后台工具边界及结果不进入持久化工具记录。

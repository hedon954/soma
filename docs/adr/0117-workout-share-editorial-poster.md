# ADR 0117：训练分享使用固定纸面海报与紧凑明细

- 状态：已采纳
- 日期：2026-09-05
- 部分替代：[ADR 0000](0000-origin-through-0.0.11.md) 的语义双主题在训练分享导出中的适用范围；App 导航、普通页面和记录事实规则仍有效
- 上游依据：维护者选定的白底黑字、橙黄色主视觉分享设计

## 背景

维护者要求分享图突出训练成绩，并明确选定橙黄色主视觉与黑色文字的纸面设计。
逐组展开会让同值训练明细冗长，普通灰色信息卡也不足以表达已选定的海报层级。

## 决策

训练分享是固定纸面输出：白底黑字、顶部 Soma 与日期、训练标题与肌群摘要。橙黄色主视觉
左侧以窄体大号数字突出有效容量，右侧使用仓库前后肌群素材；白色统计条展示完成组数、
预计消耗和总耗时。黑字保持高对比，颜色用于主视觉和肌群强度，不给每行明细染色。

海报不随系统外观改变，保证同一训练从深浅色 App 导出时一致；承载预览、关闭、保存与
系统分享的原生弹层继续适配双主题。固定导出字号，长标题和异构明细扩展纸面高度；
VoiceOver 可读出动作与完整摘要。

动作名与合并摘要优先同排，放不下时完整换行。复用 `WorkoutRecordDraft.displayRuns`，
只合并连续同值逻辑组，忽略间歇差异，不改变原记录顺序；保留不同重量、次数、时长、
左右侧和组类型。对称左右侧压缩为左右各，异值分别表达。未知重量保持未知，零才是自重。

导出仍由本地 ImageRenderer 与确定性记录投影完成，不包含真实媒体、位置、账户或远程数据流。
不更改持久字段、容量与热量公式。普通肌群图继续使用原灰色卡片，纸面样式只供分享使用。

## 未选择的方案

逐组平铺并在第四段截断；彩色明细文字；以截图贴图替代动态数据；跟随系统深色改变纸面颜色。

## 结果

训练成绩、肌群图与紧凑明细形成稳定层级。同一记录从不同 App 外观导出时保持一致；
海报专用色板和肌群呈现模式与普通页面隔离，长内容通过增高纸面保留完整事实。

## 验证

产品边界见[完成后分享验收](../acceptance.md)。

摘要回归覆盖连续同值、异构顺序、左右对称与非对称、未知值、计时组和类型；渲染检查固定
纸面在深浅外观下像素一致、大容量与长中文不截断。模拟器检查分享、保存入口、关闭、滚动、
大字号和安全区，完成 `make verify` 后提交；真机仅安装，由维护者手动启动。

# ADR 0154 · 动作受力块 ID

- 状态：已采纳
- 日期：2026-11-19
- 版本：0.0.38
- 部分替代：[ADR 0000](0000-origin-through-0.0.11.md)（动作库肌群来源与写入）
- 上游依据：[PRD 082](../prd/082-coach-progress-reliability.md)、[PRD 083](../prd/083-coach-input-and-training-metadata.md)
- 下游落地：[BUG 0078](../bugs/0078-exercise-muscle-map-missing.md)

## 背景

动作库以外的新动作缺少肌群数据。详情和分享共用动作标注，缺项会同时影响这两个入口。

## 决策

教练创建动作时选用程序化受力图的封闭 `MuscleGroup` ID，分别保存主要与辅助肌群。设备和远程 Agent 对当前工具版本校验枚举、非空主要项以及组内和组间重复。动作身份不明确时沿用受控提问。

现有动作肌群数组继续存储 JSON 字符串。新标注写入稳定 ID，读取时转换为用户可读名称，已存别名继续参与同一受力图投影。内置目录只补缺项。动作级元数据供动作库、已有训练详情和分享汇总共用。历史工具版本仍可恢复执行。

## 结果

分享汇总可使用新建和补齐后的受力标注。设备端数据库与备份格式保持可读，远程执行需配套支持 v5 的服务版本。

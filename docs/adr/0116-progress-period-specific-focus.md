# ADR 0116：进展按时间粒度组织信息

- 状态：已采纳
- 日期：2026-09-05
- 部分替代：[ADR 0114](0114-progress-periods-and-adaptive-energy.md) 的四周期共用摘要层级；日期边界、能量估算和原始记录规则不变
- 上游依据：[PRD 054](../prd/054-progress-history-and-periods.md)，维护者确认日看记录、周看执行、月看变化、年看长期积累

## 背景

日页重复展示“训练 1 天”和最近体重，挤占当天明细；周、月、年仅变换范围而没有改变信息重点。

## 决策

| 周期 | 训练 | 身体 |
| --- | --- | --- |
| 日（默认） | 直接列当天动作记录，保留分享 | 直接列当天测量与时间 |
| 周 | 训练天数、工作组；每日训练分布 | 有测量日的平均体重、逐日轨迹 |
| 月 | 总容量、天数和工作组；按自然周画容量 | 最新体重、月内首末测量变化 |
| 年 | 累计训练天数、有训练的月份；按月画天数 | 月均体重、首末有测量月份的均值变化 |

- 日页不再显示重复的训练／身体摘要卡；切 Tab、返回详情保持手动选择。
- 周均按每天最后一次有效体重等权计算，月内变化也使用日代表值；没有测量的日不插值、不补零。
- 年内月均沿用现有体重详情的实际测量均值，月均变化不是体脂或减脂结论；只有一个有测量月份时不显示变化。
- 月容量按自然周分桶并裁剪到当月；未发生的周不补零。不把不同动作容量解释为力量提升。
- 摘要、图表使用不可变派生值，复用原记录、详情和分享；不增加持久字段或远程数据流。
- 饮食与能量保持已确认的日明细、周月年日均及图表口径，不为区分周期增加装饰文案。

## 未选择的方案

仅修改标题但保留相同摘要；每天展示训练天数；无观测时补体重；用单日体重波动判断减脂效果。

## 结果

日页优先审查今天，长周期分别突出执行频率、阶段训练量和长期积累；原记录始终可以进入编辑。

## 验证

确定性测试覆盖去重训练日、自然周边界、容量相加、日代表体重、月内差值、月均与缺测。
UI 验证默认日、日页无重复卡、三种周期摘要、浅深色、下钻返回及当天分享。

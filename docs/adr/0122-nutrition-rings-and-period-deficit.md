# ADR 0122：营养圆环、推荐摄入与日页对照

- 状态：已采纳
- 日期：2026-09-07
- 维护者：Soma maintainers
- 上游依据：[PRD 057](../prd/057-coach-focus-progress-rings-and-library-clarity.md)
- 部分替代：
  - [ADR 0000](0000-origin-through-0.0.11.md) 的日页线性宏量与缺口文案呈现；Mifflin／PAL 估算不变
- 后续替代：暂无

## 背景

日页只列出蛋白质／碳水／脂肪克数，没有推荐对照。周／月把多日累加成环既占空间，也不能代表
任何一天。用户要在当天看圆环进度，并且状态只靠颜色。

## 决策

- 日页四枚独立环：上中热量，下排蛋白质／碳水／脂肪。顶部事实卡写已记录摄入与预估总消耗；热量环心
  写已摄入／推荐摄入 kcal，不写还可摄入或完成百分比。缺目标时环心只写已记录热量。热量环不重复
  「热量」；宏量把 g 写在数字同一行，名称留在环下。蛋白质／碳水／脂肪图标用肉块、麦穗、油滴，
  颜色分别为 vital、trainingLoad、trend。点按热量环打开既有摄入明细；点按宏量环打开该营养素
  的餐次克数明细，缺项显示未记录。明细只列分项，不重复卡面已有的摄入／消耗／宏量汇总。当日摄入
  低于推荐热量时，底部再用一句仍可摄入，不可点开浮层。
- 外层卡保持中性 card 表面，不用绿色渐变铺底。主环只保留锐利进度弧和紧贴的一层弱光；营养环
  更弱。不把整圆或整张卡模糊成绿雾。
- 热量环：已记录摄入相对推荐热量。推荐热量在当日预估消耗上按目标微调：增肌 +250 kcal，
  减脂 −400 kcal，增肌减脂或未填目标为维持。这是产品起步假设，不是医疗处方，不写回资料。
- 宏量环：有体重时蛋白质按目标 1.8／2.0／2.0／1.6 g/kg（增肌／减脂／增肌减脂／未填）；脂肪为
  推荐热量的 25%／9；碳水吃掉剩余热量／4。缺体重则只显示已记录克数，不画目标，也不给状态色。
- 进度阈值：摄入／目标低于 0.85 为不足，0.85–1.15 为范围内，高于 1.15 为超量。不足与范围内用该
  环的指标色，进度弧表达差额；超量才用生命体征红。可见层不写「不足／超量」；VoiceOver 必须读出。
- 环上颜色：热量用 meal，蛋白质用 vital，碳水用 trainingLoad，脂肪用 trend。轴、轨、分隔中性。
  四环不得共用提醒黄。
- 营养环只出现在日页。周、月、年只保留日均摄入／消耗和图表，点图不切换周期。
- 摄入／消耗仍可点开原有彩色分项。估算公式与去重规则不改。

## 未选择的方案

- 把训练 kcal 再加进圆环：PAL 已含活动。
- 用几天体重变化自动改推荐：PRD 053 尚未授权摄入校准。
- 可见状态文案：用户明确只要颜色；无障碍走 VoiceOver。

## 结果

### 正向影响

- 当天能立刻看到吃了多少、相对推荐差多少；周月回到日均对照，不再被累加环占位。

### 成本与限制

- 推荐值依赖体重、性别可用的静息估算和用户目标；缺资料时圆环降级，不编造目标。

## 验证

`NutritionTargetCalculatorTests`、`ProgressHistoryProjectionTests`、`ProgressEnergyBreakdownTests`
覆盖公式、周月不建环、缺测和宏量明细。浅色／深色模拟器检查圆环对比度。`make verify`。

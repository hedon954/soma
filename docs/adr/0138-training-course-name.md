# ADR 0138：动作处方的产品名是训练课程

- 状态：已采纳，已实现
- 日期：2026-09-29
- 版本：0.0.26
- 维护者：Soma maintainers
- 上游依据：[PRD 069](../prd/069-training-course-name.md)
- 部分替代：[ADR 0000](0000-origin-through-0.0.11.md)（仅「训练计划 GUI」这一产品用词；聊天优先与带练例外仍然有效）
- 后续替代：暂无
- 下游落地：[验收](../acceptance.md)

## 背景

`TrainingProgram` 保存的是一堂课的当前处方。产品一直把它叫做训练计划，而接下来的训练计划
需要表示开始日、周期和每一天指向哪一堂课或休息。继续共用名字会让模型和界面把两件事写成同一个对象。

## 决策

用户可见文案、Agent 对用户说话时使用的中文，以及工具描述里的中文名词，把现有处方叫做训练课程。
`TrainingProgram`、`program_id`、`create_program` 等标识符保持不变。已开始的 Session 快照、
备份字段和历史 changelog 不改写。

内置 Skill 的默认 Markdown 改为制定课程，并且不在课程正文里安排每周频率。用户已经保存的
Skill 修改不被这次默认文案覆盖。

## 未选择的方案

- 立刻把 Swift 类型改名为 Course。标识符迁移会波及备份、测试和工具协议，对用户没有额外结果。
- 保留「训练计划」给现有处方，给排期另起一个名字。排期才是用户口中的计划，课程才是一堂课。

## 结果

### 正向影响

- 后续训练计划可以占用这个名字，而不必再解释「计划其实是一堂课」。

### 成本与限制

- 旧对话和旧文档里仍会出现训练计划，指的是当时的处方。
- 模型若沿用用户自己改过的 Skill，仍可能说出旧词。

## 验证

- 界面与工具描述检索不再把现有处方叫做训练计划。
- `make check` 通过。

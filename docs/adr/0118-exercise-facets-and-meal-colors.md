# ADR 0118：派生动作筛选与固定餐次配色

- 状态：已采纳
- 日期：2026-09-05
- 上游依据：[PRD 055](../prd/055-exercise-facets-and-meal-breakdown.md)
- 部分替代：[ADR 0115](0115-energy-default-reference-and-compact-details.md) 的摄入分项呈现，估算与周期口径不变

## 背景

[ACE 动作库](https://www.acefitness.org/resources/everyone/exercise-library/) 使用身体部位、器械和难度；[Hevy 动作库](https://www.hevyapp.com/features/exercise-library/) 提供器械、肌群筛选。Soma 当前事实字段是主要肌群、辅助肌群和动作模式，没有可靠的器械或难度元数据。

## 决策

- 左侧常驻身体部位、动作模式、受力肌群三条分类分支。点击部位展开下级主要肌群；选中一个分类路径，右侧列表立即更新，并与顶部名称搜索取交集。左右列表独立滚动，不需要弹窗和完成按钮。
- 身体部位从主要肌群做确定性解剖映射，精确肌群筛选保留原标签，避免受力图的粗粒度别名合并改变肌群身份。
- 未映射部位归入未标注，未知模式与肌群保留入口；自定义文本保持可检索，不假造器械、难度或训练类型。
- 分类投影随动作增删改刷新，搜索时只匹配已解码的内存值，不在每个按键逐项解码持久数据。
- 原位摄入浮层按记录中已有餐次增加前缀，餐次使用稳定色标与同色数值；文字保持中性。汇总行使用中性色，避免被误认成另一餐。
- 配色集中在餐次展示层，复用经过对比度验证的双主题色值，不用指标业务角色为餐次命名。
- 日明细未知热量与真实零分开显示；周期统计仍复用原投影，不改变聚合与有效日口径。

## 未选择的方案

- 从动作名猜器械或从训练负重推难度：事实不可靠，还会引入重复的分类真值。
- 按固定单一大类分组：复合动作跨部位，无法同时按模式与肌群缩小范围。
- 按行号轮换颜色：排序或增删记录会改变同一餐次颜色。

## 结果

分类浏览覆盖已有资料并保留未知信息，餐次在同一弹层中可快速区分。无数据库迁移、新依赖或远程数据流；分类精度受当前动作标注完整性约束。

## 验证

`ExerciseLibraryFilterTests`、`ProgressEnergyBreakdownTests`、`AppThemePaletteTests` 和 `LibraryAndMealsUITests` 覆盖分类路径、数据真值、双主题；`make verify` 为完成门禁。

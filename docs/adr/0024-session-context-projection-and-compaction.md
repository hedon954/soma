# ADR 0024：投影最近十个 Session 来回并恢复历史媒体

- 状态：部分已替代（健身房紧邻跨轮媒体归档由 ADR 0026 补充；更早轮次 digest 与上下文包由 ADR 0047 修订）
- 日期：2026-07-30
- 维护者：Soma maintainers
- 后续替代：
  - [ADR 0026](0026-bounded-gym-media-attribution.md) 放开受限的健身房紧邻媒体归档
  - [ADR 0047](0047-deterministic-context-pack-and-cross-turn-facts.md) 用确定性上下文包与十轮外 digest 修订「不做滚动摘要 / 两行 structuredContext」边界

## 背景

当前跨 Turn 上下文只拼接最近八条消息，每条最多 160 字；角色关系被压平成摘要，之前的媒体
也无法再次进入模型。这既无法表达十个真实来回，也无法支持“继续看刚才的视频”。如果反过来
每轮重发完整 Session 和全部媒体，成本、延迟和隐私暴露又会随会话无限增长。

## 决策

- 完整消息、媒体引用、Event Cards 和 Trace 是本地审查事实，永不因上下文压缩而删除。
- `ConversationContextProjection` 只读取当前 Session，选择最近十个用户 Turn；每个 Turn
  配对其最后一次 Agent Attempt，按原始 `user → assistant` 角色顺序发送。当前输入作为新的
  user 消息追加，不混入历史。
- 十个来回保留完整文字，不再对每条消息执行 160 字截断。更早对话当前不生成滚动摘要；
  精确业务历史通过确定性查询工具读取。
- 上下文严格限制在当前 Session。跨 Session 只共享已经进入结构化模型的个人事实。
- 最近十个来回内的历史用户媒体从 App 沙盒重新准备，并继续挂在原来的历史 user 消息上。
  单次请求沿用十二张视觉帧总额度：当前 Turn 优先，剩余额度按历史 Turn 从近到远分配。
- 原始附件存在但没有进入额度或准备失败时，历史提示明确写出实际重新提供的帧数；模型不能
  把“曾有媒体”当成“本次看到了画面”。
- 历史媒体默认仅是推理上下文，`ConversationRecorder` 和 Tool 写入只接收当前 Turn 的
  `MediaAttachmentReference`。唯一例外由 [ADR 0026](0026-bounded-gym-media-attribution.md)
  定义：`update_gym` 可在严格条件下归档紧邻上一轮的健身房照片。
- 视频先由模型能力矩阵选择输入方式：百炼中确认支持且稳定副本不超过 24MB 时发送视频
  Data URL；其他平台、能力未知、超限或直接请求在首个响应前被拒绝时使用关键帧。
- 附有视频时必须存在有效的直接视频内容或大于零的关键帧；否则 Attempt 失败，不能把
  `hasVideo=true` 的文字说明伪装成视觉输入。
- 图片首次发送、重试和历史恢复都使用同一份标准化 JPEG。Trace 记录历史来回数、附件数和
  实际帧数，不记录媒体内容、Base64 或私有路径。
- 历史媒体恢复失败不破坏完整本地历史；请求仍保留对应文字，并明确该轮没有重新提供画面。

## 未选择的方案

- 永远只取最后八条并截到 160 字：边界粗糙、角色失真且无法表达十个来回。
- 每轮发送完整 Session：成本和隐私暴露无上限。
- 不设视觉额度重发十个来回内的全部媒体：流量、延迟和供应商暴露不可控。
- 当前就引入滚动摘要：会增加派生状态、更新时机和事实污染风险，用户当前明确选择固定十个
  来回。
- 跨 Session 自动拼接原始聊天：破坏用户选择 Session 的语义。

## 结果

### 正向影响

- 长 Session 的文字边界固定为十个来回，用户仍保有完整本地历史。
- 后续追问可以读取窗口内旧媒体，而不是依赖文字提示想象画面。
- Turn、Attempt、媒体选择和降级都能在 Trace 中解释。

### 成本与限制

- 单条回复本身极长时，固定十个来回仍可能接近小上下文模型的限制；模型路由必须避免把
  超长多模态历史发送给容量不足的小模型。
- 十二张视觉帧额度可能让较早媒体只保留文字，Trace 和提示必须如实说明。
- 直接视频的格式和限制因供应商而异；关键帧降级仍不能等价于完整视频时序理解。

## 验证

- 构造十一轮以上会话，验证只发送最近十个用户 Turn 及每个 Turn 的最后一次 Agent Attempt，
  本地历史保持完整。
- 当前 Turn 占满十二张视觉帧时历史媒体不发送；当前无媒体时从最近历史向前分配。
- 同一 Session 历史媒体进入原 user 消息，跨 Session 媒体完全隔离；历史附件不进入当前
  Tool 写入。
- 合成视频覆盖内联直传、超限降级、抽帧成功和零帧失败，失败时不发起无画面的视觉请求。

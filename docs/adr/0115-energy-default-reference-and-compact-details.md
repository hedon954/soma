# ADR 0115：能量估算默认参考与紧凑明细

- 状态：已采纳
- 后续替代：[ADR 0118](0118-exercise-facets-and-meal-colors.md) 细化摄入餐次与未知值呈现
- 日期：2026-09-05
- 部分替代：[ADR 0114](0114-progress-periods-and-adaptive-energy.md) 的无手动配置则停止估算、指标仅经依据页披露规则；动态校准、历史因果与去重不变
- 上游依据：[PRD 053](../prd/053-adaptive-energy-estimation-and-progress.md)、[PRD 054](../prd/054-progress-history-and-periods.md)，维护者本轮要求有静息即可估算、明细简化

## 背景

只有静息公式但没有设备历史或手动系数时，原规则拒绝估算；依据页又用多个分组和说明掩盖关键数值。

## 决策

- 活动系数优先级：充分设备历史 → 当时有效的个人设置 → 默认参考 1.4。
- 默认参考是产品起步假设，不是用户生活方式事实，不写入个人设置，也不冒充动态校准。
  FAO 的久坐／轻活动 PAL 范围为 1.40–1.69；取低端作为起步参考是产品选择，
  不声称 PAL 与基于静息公式的有效系数严格等同。[依据](https://www.fao.org/4/y5686e/y5686e07.htm)
- 非动态路径优先用本地全天静息公式；公式不可用时，可用过去 30 天最近一个覆盖充分的完整设备静息日。
  当天部分静息、未来记录、冲突重复或无效能量不可充当全天基准。没有有效静息仍显示缺资料。
- HealthKit 不可用不阻断本地估算；训练消耗单列，不再叠加至已包含活动的全天预估。
- 能量依据使用一张紧凑明细列表：日期、静息、带来源的活动系数、总消耗、摄入、缺口、训练消耗。
  多周期可切换要查看的日期。公式、设备覆盖、缺项和读取错误收进计算明细，不常驻铺开。
- 摄入和总消耗数值各自点击后原位弹出彩色明细：色标、名称、数值；摄入列餐食，消耗列静息、活动等消耗和系数。
  多周期明细采用与首页日均值相同的已结束有效日，不误用最后一天，不增加大标题、教学文案或重复说明。
  浮层不显示备注或副标题，高度随实测内容收紧；来源和缺项仍可在能量依据页审查。
  无障碍大字号使用系统可滚动 Sheet，避免锚点靠近底部时被压成不可读窄缝；普通字号保持原位浮层。
- 无持久字段、迁移、原始记录回填或新远程数据流。

## 未选择的方案

把静息当作总消耗、把默认值写成用户事实，或继续要求用户先填系数才能查看估算。

## 结果

仅静息即可获得标明默认参考的初始结果，个人设置和动态历史仍优先；明细默认只呈现数值。

## 验收

静息有值但无设备／设置时立即估算；个人设置和动态历史优先；非法值、未来与部分日被拒绝。
双主题、长文本与大字号检查独立点击和紧凑浮层，确认设备读取失败不覆盖本地结果、分项不重复加训练。

# ADR 0008：对话处理属于 App 生命周期

- 状态：已采纳
- 决策阶段：2026-07-29

## 背景

模型解析和多轮 ReAct 可能持续较长时间。如果 Task 绑定在聊天 View，用户切到进展页或设置页时任务可能被取消，迫使用户一直停留在发送页面。

## 决策

- 使用 App 根层持有的 `ConversationProcessingService` 管理一次在途任务。
- 聊天 View 只提交任务并订阅实时状态。
- 用户在 App 内切换页面时，处理继续执行并持续写入当前数据空间。
- 同一时间只允许一个在途对话，避免上下文、附件和写入状态交叉。
- App 被系统终止后不承诺继续执行；当前不引入后台上传或服务器任务队列。

## 未选择的方案

- View 本地 Task：生命周期太短。
- iOS 后台长期运行：不适合不可预测时长的网络 Agent，也超出本地 MVP 范围。
- 后端异步任务：破坏本地优先边界并引入账号/同步问题。

## 结果

“异步”在当前版本中意味着不必停留在聊天页，但仍依赖 App 进程存活。未来若引入可恢复任务，需要新的持久化队列 ADR。

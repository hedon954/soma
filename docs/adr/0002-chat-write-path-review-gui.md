# ADR 0002：聊天是唯一创建路径，GUI 负责审查

- 状态：部分已替代
- 决策阶段：2026-07-27 至 2026-07-28
- 后续替代：[ADR 0030](0030-deterministic-guided-workout-and-session-recording.md) 允许带练直接保存用户确认的逐组事实

## 背景

早期界面按训练、饮食、身体和健身房拆分新增表单，功能完整但操作仍然要求用户先理解数据库结构。产品目标是让用户直接说、拍或录，AI 自动判断和记录。

## 决策

- 文字、图片、视频和语音都从教练对话进入。
- 不提供训练、饮食、身体或器械的传统“新增”表单。
- 进展页保留列表、详情、编辑、保存和删除，作为 AI 数据的审查界面。
- 当前健身房是对话建议的高频上下文，在输入框上方提供紧凑切换；完整健身房管理在设置中。
- 顶层界面收敛为“教练”和“进展”。

## 交互约束

- 详情进入即编辑，只有产生修改才显示保存。
- 列表采用左滑红色垃圾桶删除，不重复显示“删除”文字。
- 每个编辑字段保留可见名称，不能在输入后丢失语义。
- 对话正文使用原生文本选择，支持划句复制。

## 未选择的方案

- 五栏 Tab：功能暴露充分，但强化传统 GUI 心智并增加视觉噪声。
- 完全没有列表：界面更少，却让用户无法审查 AI 是否记对。
- 所有管理都塞进聊天：不适合批量回看、比较和纠错。

## 结果

聊天负责降低录入成本，GUI 负责建立信任。任何新增业务能力都应优先考虑如何进入这条闭环，而不是先增加新的顶层页面。

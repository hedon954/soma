# BUG 0047：终态失败重试残留旧错误

- 状态：已修复，待真机网络故障复验
- 发现日期：2026-09-02
- 影响范围：Agent 终态失败、手动重试和消息元信息
- 上游依据：维护者截图与重复反馈
- 下游落地：
  - [PRD 052](../prd/052-coach-training-and-lifecycle-reliability.md)
  - [ADR 0111](../adr/0111-agent-response-identity-and-manual-recovery.md)

## 症状

用户手动重试后，旧“执行失败”卡仍留在聊天页，下面又出现“正在继续处理”；失败时间、日志和反馈
按钮间距也不一致。

## 根因

终态失败恢复没有强制绑定原 `responseMessageID`，重试启动只追加 running 投影，没有先清理失败
文本和失败 Turn Item。元信息控件又按剩余空间分散布局。

## 修复

- 入队即预建并绑定响应；失败与人工重试始终复用同一消息。
- 重试开始移除旧错误/失败文本，保留已成功 Tool，只继续未完成检查点；再次失败仍原位显示。
- 时间、日志和反馈使用一致小视觉间距，同时各自保留 44pt 触达区域。

## 回归门禁

- 临时 SwiftData 容器验证同 ID、失败清理、成功步骤保留和再次失败。
- 真机断网/恢复后手动重试，聊天中只能有一个响应气泡。

## 验证

相关 Job、FIFO 与人工恢复测试已通过；真机网络故障验收待补。

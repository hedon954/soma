# BUG 0074 · 训练记录变动后仍可提交旧重量校正

- 状态：已复现并修复，独立磁盘库回归通过
- 上游依据：[PRD 082](../prd/082-coach-progress-reliability.md)

## 症状

在预览与确认之间修改旧聚合训练的总次数，批量操作仍会按旧预览应用。带练实际侧别的次数改变，或校正后实际组改归另一次带练，旧路径也可能继续应用或撤销。

## 根因

确认时主要比较重量。带练实际组的归属、组状态和实际次数与时长未和投影重新核对，旧记录的总次数也未重新验证。撤销清单由页面在服务校验前保存，可能留下一份从未有效应用的旧预览。

## 修复

写入前重验记录身份、旧聚合总次数、带练实际来源及其投影。清单里任一项变化会阻止整批操作。校验通过后先保存受文件保护的撤销清单，再用一次数据库提交更新实际重量与投影。应用重试复用原清单，撤销须有对应的清单。已撤销的清单可以在重新核对原值后更新预览，覆盖目录补充的别名。

## 回归门禁

`WorkoutWeightCorrectionTests` 检查总次数变化、带练实际次数变化与改归其他带练时拒绝写入。磁盘回归覆盖校验失败不写清单、原始 40 kg 和 20 kg 只折半一次、19.99 kg 保持原值、重开后继续使用原清单、清单缺失时拒绝撤销，以及完全撤销后可以用新方案替换旧清单。

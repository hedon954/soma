# BUG 0072 · 营养表列标题被遮挡后数值串列

- 状态：已复现并修复，模型端到端验收待进行
- 上游依据：[PRD 082](../prd/082-coach-progress-reliability.md)

## 症状

双列包装标签的「每份」标题被反光遮挡后，仍清晰可读的每份热量和蛋白质会被归到左侧「每 100 g」。中文营养表直接使用「每 100 克」或「每 100 毫升」时，旧版也会漏掉份量基准。

## 根因

列归属只检查数值是否在可见标题的起点右侧。只有一个可读标题时，右侧没有边界。基准识别只解析拉丁字母单位。

## 修复

用标题实际边界和数值位置确认列归属。相邻的 kJ 与 kcal 可以属于同一格。无法归属的数值只触发核对提示。基准识别支持中文单位并按同一换算规则输出。重新引用历史标签时，设备证据注明原回复对应的回合与图片序号。

## 回归门禁

`CoachProgressReliabilityTests` 用经过 JPEG 压缩的双列合成标签遮挡右侧标题。旧行为把右列的 50 kcal 与 3.7 g 都归到左列。修复后保留左列两种能量单位和清楚的脂肪读数，右列提示核对。回归还覆盖中文基准、同列单位冲突，以及在下一轮引用原始第二张图时保留图片序号。

# BUG 0073 · 已失效的教练建议仍可提交

- 状态：已复现并修复
- 上游依据：[PRD 082](../prd/082-coach-progress-reliability.md)

## 症状

有一条已完成回复，用户明确说过训练结束。即使该回复引用的训练记录已不存在，旧路径仍会推荐「帮我总结今天这次训练」。历史会话中当天补发的回复也可能出现面向当天的建议。

从历史回到当天时，候选会在首次定位消息尾部之后出现。如果输入栏盖住新按钮，界面检测仍可能报告按钮可点击，实际触控落在输入区。

## 根因

旧路径把回复中的业务卡引用当成可执行证据。显式结束的训练分支跳过了实际记录校验。建议使用当前选择的会话提交，未再次核对来源回复、会话及资料版本。

## 修复

基于实际记录计算建议，业务保存后刷新候选。发送前核验作用范围与当天查询结果，使用来源回复绑定的会话提交。检查期间只接受一个操作。用户切换会话或暂离教练页时取消未完成的提交。

候选出现前，若教练正跟随消息尾部，安排一次布局后的尾部定位。用户已经上滑浏览时，保留当前阅读位置。

## 回归门禁

`CoachTabBehaviorUITests` 覆盖有饮食但缺训练时隐藏训练建议，历史会话收起当天建议，以及训练总结、热量查询各自双击只形成一对问答。

# BUG 0078 · 训练关联动作缺少受力标注

- 上游依据：[PRD 082](../prd/082-coach-progress-reliability.md)、[ADR 0154](../adr/0154-exercise-muscle-map-ids.md)

## 症状

训练详情只绘制轮廓，分享海报的受力图也没有高亮。

## 根因

创建工具只保存名称、完成方式和侧别。没有内置目录条目的动作缺少训练详情与分享汇总依赖的肌群数据。

## 修复

创建动作使用受力块 ID，按主要和辅助两组校验后保存。旧库通过维护构建加载本地核对清单，预览后按动作 ID 补标。查看训练详情和分享时实时读取关联动作，旧记录可直接使用补齐的数据。

## 回归门禁

回归覆盖非法、重复及缺失 ID，旧工具请求恢复，保存后重新读取，已标注动作保护和分享汇总。

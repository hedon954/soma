# BUG 0054：视频输入降级、播放生命周期与听写草稿覆盖

- 状态：已修复，自动回归通过；真实中文听写与真机声画待验收
- 日期：2026-09-05
- 修订自：[BUG 0002](0002-video-frame-extraction-silent-fallback.md)、[BUG 0012](0012-direct-video-and-first-delta-timeout.md)、[BUG 0048](0048-speech-segment-overwrites-committed-text.md)
- 上游依据：[PRD 056](../prd/056-video-speech-and-share-readability.md)、[ADR 0119](../adr/0119-full-video-and-append-only-dictation.md)

## 症状

用户发送视频后只得到关键帧分析，点开附件没有自动播放，手动播放也无可靠反馈；听写期间修改草稿后可能被旧基线与累计识别结果覆盖。分享明细的同值组还会被间歇及记录元数据拆散。

## 根因

视频能力未知与瞬态失败进入抽帧支路，改变了原始证据的覆盖范围。旧播放器在 View 初始化阶段创建，没有明确的所选页播放意图和可播放/失败处理；共享音频会话可能仍处于录音模式。未取得用户原文件作复现，不能把手动播放故障归为唯一已证实原因。

听写将开始时草稿和历史段缓存后回写输入框，用户的实时编辑不再是唯一事实来源。分享复用编辑用连续组签名，把间歇、组类型或中间穿插的不同组当成拆分依据。

## 修复

完整视频贯穿准备、当前/历史输入与重试，不可用明确失败。播放器由页面稳定持有，只让当前页播放，加载前切换 playback 音频会话，失败给出重试，关闭释放播放器及查看器音频会话。

听写服务只管理当前未确认片段，确认后直接追加当前草稿；停止发送前等待最终结果，切会话取消并隔离旧回调。iOS 26 支持时使用 SpeechAnalyzer 本地模型，旧路径保持严格本地。音频重采样停止时排空尾部，避免丢失末尾声音。

分享独立按重量、次数/时长和左右事实合并全部同值组，不改原始训练记录，每个合并项在动作卡内独立展示。

## 回归门禁

- FullVideoInputTests：完整字节、消息位置、无 fps/图片替代、缺失文件阻断；合成两秒视频自动播放时间前进、暂停恢复、后台、关闭、失败。
- Server provider 测试：瞬态重试保持完整视频，明确不支持与旧关键帧 Job 在发送前失败。
- SpeechInputSessionTests / CoachComposerStateTests：手工修改、清空、切会话、迟到回调、最终尾句只追加一次、重采样时长与标点。
- WorkoutSharePosterBuilderTests / RenderingTests：跨间隔同值合并、忽略间歇、左右差异、缺失数据、动作内多卡。
- WorkoutShareUITests：正常字号浅深主题、滚动和保存入口；make verify 为提交前完整门禁。

## 真机验收

使用合成或演示视频发送到支持完整视频的已配置模型，核对实际模式并观看自动/手动声画播放。支持设备首次下载中文资源后，连续听写并手改草稿，停顿继续，立即停止发送；断网验证本地识别。安装后由维护者手动启动，不自动启动 App。

# BUG 0070 · 内存数据空间启动误清理磁盘附件

- 状态：已修复，模拟器回归通过
- 发现日期：2026-11-19
- 影响范围：复用已有 App 沙盒、并以纯内存库启动的测试和性能采样

## 症状

用 0.0.36 建立合成磁盘库和照片后，同一 App 沙盒中的测试进程仍能读到原有记录和附件路径，却打不开该照片。相同照片仍可从此前建立的加密备份恢复。

## 根因

启动时的媒体维护用个人库和演示库收集保留路径，再清理共享 `PrivateMedia` 中无法匹配的文件。测试和性能采样可以用内存库启动。内存库没有磁盘记录的引用，但维护仍会扫描磁盘目录并记录清理已完成。

## 修复

个人库和演示库均使用磁盘配置时，才允许清理并记录完成状态。

## 回归门禁

`MediaStorePathTests/testInMemoryContainersDoNotRunPersistedMediaCleanup` 在独立模拟器用临时文件复现。修复前文件被删。修复后文件内容完整，清理完成标记也没有写入。

正常启动的磁盘库场景也已验证。启动清理删除了另放入的合成孤立文件，并保留旧库仍在引用的照片。

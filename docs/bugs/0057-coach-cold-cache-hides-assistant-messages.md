# BUG 0057：冷启动后教练页只显示用户消息

- 状态：已修复
- 发现日期：2026-09-08
- 影响范围：重新进入 App 或内存警告后的教练会话
- 上游依据：维护者复现：回前台只剩自己发的气泡，发一条或重进 Session 才出现 AI 回复
- 下游落地：[PRD 059](../prd/059-coach-ids-progress-and-required-zeros.md)

## 症状

杀掉或长时间挂起后再打开，教练页只渲染用户消息。AI 正文和结果卡要等再次拉取才出现。

## 根因

ADR 0125 用渲染缓存当可见性门禁。用户气泡被当成已绘制；助手气泡要 Markdown 缓存命中。
`NSCache` 在后台被清空后，`didPrepareVisiblePage` 仍为 true，过滤器只留下用户行。

## 修复

当前窗口的消息立刻展示，不再等排版完成。原位记录卡缓存未命中时仍会补查，不把
`allowsDeferredLoad` 限制在最后一条助手消息。

## 回归门禁

- `CoachMessageVisibilityTests`：未排版完成时仍包含助手消息。
- 手工：有 AI 历史的会话，杀进程再打开，应直接看到助手气泡。

## 验证

单元测试覆盖可见性规则。真机杀进程复验由维护者确认。

# BUG 0071 · 完整视频未经能力确认就发送

- 状态：已复现并修复，提供方实测待验收
- 上游依据：[ADR 0152](../adr/0152-coach-progress-reliability.md)

## 症状

发送训练视频或引用历史视频时，模型目录未声明完整视频能力，旧路径却进入模型请求。模型首次拒绝后，若任务已经保存初始检查点，用户换模型再重试仍会使用旧模型。

## 根因

本机 Agent 的发送门槛只覆盖能力明确为否及通用多模态不支持两种情况。检查点保存首次模型选择，通用失败处理保留该选择以便恢复已产生的结果。

## 修复

本机将所选模型的目录证据作为完整视频请求的前置条件。能力未知时，只查询目录。确认后使用完整视频并保持原消息位置。首次模型拒绝且没有可见输出或工具进展时，手动重试可以读取新的模型配置。已有进展的检查点继续绑定原配置。

## 回归门禁

`FullVideoInputTests` 验证未确认能力的模型不会收到当前或历史视频、目录确认后能保留完整字节及消息归属，以及首次拒绝和已有进展时的恢复边界。模型时序能力另按 [训练视频时序验收](../engineering/video-timing-validation.md) 实测。

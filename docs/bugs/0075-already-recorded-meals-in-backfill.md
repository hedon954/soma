# BUG 0075 · 补餐提醒要求重复核对已有记录

- 状态：已复现并修复
- 上游依据：[PRD 082](../prd/082-coach-progress-reliability.md)

## 症状

用户已经记录了三餐，历史补记里仍出现多条「核对餐次」，加餐也计入待办。一日可以出现四条待核对。进展可能把已有三餐且热量齐全的旧日排除在周月缺口之外。

## 根因

补餐列表将缺少的餐次、未手动确认的餐食和缺热量的记录混合计数。进展只把手动确认过的餐次计入覆盖，已有的自动分类未生效。

## 修复

按自然日计算早餐、午餐和晚餐三个槽位。已存有效餐次和已标记「没吃」的槽位直接覆盖。教练的当天提醒再按时间筛选，过去日期只显示实际缺餐。热量缺项继续影响能量差额是否可计入，单独展示统计状态。

## 回归门禁

`CoachProgressReliabilityTests` 覆盖晚上 8 点只提示到期缺餐及昨天缺一餐或三餐。`LibraryAndMealsUITests` 覆盖已有餐及加餐隐藏、历史分组计数、没吃与撤销、带日期的补餐草稿。`ProgressEnergyDeficitTests` 覆盖旧三餐热量齐全时纳入周月、缺餐或缺热量时排除。

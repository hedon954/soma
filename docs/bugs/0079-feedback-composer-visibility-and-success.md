# BUG 0079 · 反馈发送按钮被遮挡与成功确认无法退出

- 修订自：[BUG 0031](0031-feedback-sheet-transition-jank.md)（逐回复反馈底部定位与成功确认）

## 症状

教练逐回复反馈在键盘弹出或输入多行内容时，发送按钮被底部快捷按钮和输入区盖住。设置页通用反馈投递成功后，「已发送」确认层持续盖在表单上，需要重启才能再次输入。

## 根因

教练只在初次展开时滚动到反馈底部。键盘改变聊天可视范围、输入框长高时，没有针对当前反馈重新定位。两个反馈入口都以嵌入模式渲染，旧代码把嵌入模式一律判为成功后回调收起，设置页没有收起回调，确认状态因此一直为真。

## 修复

编辑期间追踪当前反馈与聊天输入区的布局。输入区向上占据空间或当前反馈改变高度时，将该回复的反馈底部滚到快捷按钮上方。邮件投递成功后清空草稿，确认动画结束时逐回复反馈收起，通用反馈淡出确认并恢复表单。取消确认等待同样清除成功状态。

## 回归门禁

`FeedbackComposerUITests` 使用虚构消息和本地模拟投递。在浅色、深色下验证键盘打开后的发送位置、多行输入后的按钮可点和提交后自动收起，以及设置页连续两次发送后表单恢复。真机复验使用实际中文输入法，检查候选栏高度变化和连续投递。

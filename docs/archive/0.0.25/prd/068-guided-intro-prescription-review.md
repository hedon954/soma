# PRD 068：准备动作展示并调整本次分组参数

- 状态：已采纳
- 日期：2026-09-19
- 版本：0.0.25
- 修订自：[PRD 000](../../../prd/000-origin-through-0.0.11.md) 的训练课程与带练
- 后续修订：[PRD 069](../../../prd/069-training-course-name.md)（准备页不回写的对象改称训练课程）
- 下游落地：[验收](../../../acceptance.md)、[训练领域协议](../../../engineering/training-domain-model.md)、[BUG 0066](../../../bugs/0066-guided-replacement-computed-predicate-crash.md)

## 背景

准备动作页只给动作名、示意图和提示，用户看不到这次要做的组、次数/时长、重量和间歇，
也无法在开组前改本次目标。替换动作则在打开列表时崩溃。

## 用户结果

进入尚未开始的动作时，准备页紧凑展示本次待练分组：连续相同组收成一行，写出次数或时长、
重量和动作级间歇；示意图缩小，「准备本动作」固定在底部，常规处方无需先滚动。用户可以
调整这些参数后再准备；取消不改训练。替换动作先列出未归档动作，确认最近实际参数后才
重建本次待练组。

已开始、已完成或已有实际数据/录像的当前动作不能改目标或替换。调整只写这次 Session
快照，不改训练课程和动作库。无历史或缺失值保持空，不沿用其他动作的目标。

## 数据与隐私

不新增持久字段、远程数据流或账户。替换列表和准备页只渲染不可变快照；操作回当前
Context 按稳定 ID 重新 fetch。测试只用虚构动作。

## 明确不在范围

- 不在准备页改动作定义的侧别或次数/时长设定。
- 不把本次调整回写到计划模板。
- 不恢复已完成组，不新增删除或云同步工具。

## 验收

准备页浅深主题分别紧凑展示分组参数，主操作固定可见；调整后带练使用新目标，取消保持原状。点替换不再闪退，
列表不含已归档动作，确认边界与 [BUG 0062](../../../bugs/0062-guided-replacement-retains-old-targets.md)
及 [BUG 0066](../../../bugs/0066-guided-replacement-computed-predicate-crash.md) 一致。
执行 `make check`、`make verify`。

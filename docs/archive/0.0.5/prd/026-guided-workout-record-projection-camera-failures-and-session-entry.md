## 背景

计划带练仍有三处断裂：录像请求可能一直停在“正在开启”且既无日志也无弹框；逐组事实只保存在
`WorkoutSession/ExercisePerformance/WorkoutSet`，因此完成动作不会进入用户熟悉的“训练记录”；
教练历史又只靠隐藏的左缘手势进入，部分用户无法发现。

## 用户结果

1. 录像要么在有限等待内由系统确认开始并展示取景器，要么结束启动态、记录不含私有媒体的
   诊断日志，并弹出带具体原因和恢复建议的警告框；训练事实仍可继续保存。
2. 一个动作的全部组进入完成或跳过终态后，只要至少有一组真实完成，就立即形成一条可编辑、
   可删除的训练记录；完成组按顺序保存，缺少次数或重量时保持为空，跳过组不伪装为完成组。
3. 全部动作处理完并由用户确认结束后，才把这些动作训练记录作为一次计划执行记录展示；
   计划执行继续保留跳过组、时长与录像等 Session 事实。
4. 教练页左上角恢复时间按钮，点击与左缘右滑、VoiceOver 操作打开同一个会话抽屉。

## 产品规则

### 录像失败

- 相机权限、配置、启动回调、运行中断和文件写入均必须产生成功或失败终态，不能无限停留在
  “正在开启相机”。
- 失败日志只记录阶段、错误类型、domain/code 等诊断元数据，不记录视频路径、帧、身体数据或
  其他私有内容。
- 录像启动失败使用系统警告框，不再只依赖自动消失的 toast；权限被拒时提供前往系统设置的
  恢复入口。相同错误再次重试失败时也必须再次弹出。

### 动作训练记录与计划执行

- 动作的全部 Set 都为 `.completed` 或 `.skipped` 时，Performance 才是可投影终态。
- 至少一个 `.completed` Set 才创建 `WorkoutEntry`；全跳过动作不创建空记录。
- `WorkoutEntry.setEntries` 只按原顺序保存完成组。完成事实有效但次数或外部重量未知时字段保持
  `nil`；明确自重保存为 `0`，不从计划值补齐用户未确认的数据。
- 每个 Performance 最多对应一条训练记录；重试、恢复和启动迁移使用来源 ID 幂等更新。
- 用户单独删除这条训练记录时在 Performance 保存投影抑制事实，后续启动回填或完成收口不得把
  用户明确删除的记录重新创建，普通训练趋势与最近容量也不从原始 Set 把它重新投影出来；原始
  计划执行证据仍保留，除非用户删除整个计划执行。
- 历史已完成带练在本机确定性补投影，不请求模型、不改变原始逐组事实。
- 计划执行的动作数与容量优先使用已关联训练记录；跳过组、时长、录像和恢复状态继续读取
  Session/Set。旧数据尚未补投影时允许读取原始 Set 作为兼容兜底，统计不得重复累计。
- 删除计划继续保留训练记录与计划执行历史；删除计划执行时同时删除由该 Session 生成的训练
  记录，并清理原有逐组事实与私有录像。

### 会话入口

- 教练页左上角使用 `clock.arrow.circlepath` 系统图标，VoiceOver label 为“历史对话”。
- 按钮、左缘手势和 VoiceOver 自定义操作复用同一抽屉状态与新建/选择 Session 行为。
- 按钮是可发现性的冗余入口，不新增顶层页面，也不改变自然日 Session 解析与手动继续旧会话。

## 数据与隐私

- `WorkoutEntry` 新增可空的带练 Session 与 Performance 来源 ID；`ExercisePerformance` 新增删除
  投影抑制标记，可选来源字段允许旧数据库轻量兼容。
- 开放导出与加密备份保留来源 ID，使恢复后仍可幂等识别组合关系。
- 所有新数据与录像日志留在设备上；不新增远程请求、账户、云端训练事实或媒体上传。

## 明确不在范围

- 不自动分析录像，不新增后台相机或麦克风录制。
- 不把跳过组的计划值补成实际训练数据。
- 不改变计划模板版本、Agent Tool 或自然语言训练记录入口。

## 验收

- 录像 Delegate 不回调时在有限等待后退出启动态、写诊断日志并弹警告；同样错误重试仍再次弹出。
- 拒绝权限时警告说明训练可继续并可进入系统设置；正常录像只在系统确认后显示取景器。
- 完成一组并跳过同动作剩余组后，训练历史出现一条只含完成组的记录；全跳过动作不出现空记录。
- 多动作完成前已完成动作可以在训练记录中看到；确认整次结束后训练 Tab 才出现一次计划执行。
- 重启补投影或重复完成逻辑不产生重复记录；容量趋势不重复累计 Session 与投影记录。
- 删除计划执行后关联动作训练记录、逐组事实、分析和私有录像均消失；删除计划本身仍保留历史。
- 点击左上角时间按钮、左缘右滑和 VoiceOver 操作都打开同一个可继续会话列表。

## 背景

ADR 0145 用参考日差额计算总消耗，并规定设备日活动能量不加入已经计算的步行和训练。这样可以避免重复，但也使当天记下的活动能量不影响总消耗。产品已改为把择优后的日活动能量加到「静息 × 残差系数」上。

## 决策

当前总消耗中的训练加项见 [ADR 0151](../../../adr/0151-training-energy-in-total.md)。下列公式是 0.0.32 当时的决策，不再作为「训练不得另加」的当前边界：

用户可见的预估总消耗、缺口、推荐目标和周期图表当时使用：

```text
当日静息 × 残差系数 + 所选日活动能量
```

明细必须加总：静息、基准额外消耗 = 静息 ×（系数 − 1）、活动消耗。活动消耗在能够证明训练能量已经包含在同一份所选日活动能量里、且不超过该读数时，才拆成训练活动消耗和其余活动消耗。拆开的两项之和等于所选日活动能量，不再另加训练。无法可靠拆开时，活动消耗保持整份读数。

系数只通过 `ResidualEnergyCoefficient.current()` 取得。当前实现返回既有默认数值 1.4。这个数是初始回退，不是传统全天 PAL，也不是已验证的个体残差。以后的体重或摄入校准只改这个提供方，不改消费方公式，也不在公式里写死倍率。

生活事实仍可记录，但当前不把由此得到的参考日系数当作残差系数。参考日差额、步行差额和训练时长摊销可以继续留在历史快照里，不进入当前总消耗。已有长期修正也不加到这个总量上。

所选日活动能量来自已经整包择优的一条日常活动记录。同一天出现多条时只采用一条，不把 COROS 与 Apple 相加。HealthKit `activeEnergyBurned` 不含静息。没有读数时保持空缺，不编造成 0；此时若去重后的训练有已知活动能量，只计入那部分，不编造其余日常活动。显式 0 是有效读数，不再改用训练能量。无效读数不参与总量。缺少静息时不凭活动能量生成总消耗。

训练列表和分享继续排除 `isDailyActivity`。不新增 COROS 授权或 MCP。

## 未选择的方案

- 继续把日活动能量排除在总量之外，以免和 1.4 重复：这正是要改掉的行为。
- 用日活动能量替换系数，回到「静息 + 活动能量」：会取消基准额外消耗。
- 在系数之外再减参考步行或按训练时长摊销：已经明确不采用。
- 现在用体重或摄入拟合新系数：尚未实现，也不能把 1.4 说成科学测定值。
- 把生活参考里的 1.5、1.6 或其他 PAL 直接当成残差系数：那些数描述的是另一种全天活动水平。

## 结果

当天的活动能量会改变总消耗，明细可以加总，后来的校准只需要替换系数提供方。代价是 1.4 在加上活动能量后不再表示传统久坐 PAL，自动校准暂时不改变这个总量。

## 验证

`DailyEnergyTotalTests`、`DailyActivityEnergyTests`、`AdaptiveEnergyEstimatorTests` 和能量投影测试覆盖公式、明细加总、活动能量敏感性、训练不重复、系数提供方和缺数。`make check` 能跑的静态门禁在本环境执行；iOS 模拟器构建受环境限制时在 PR 中说明。

  - [PRD 033](../../0.0.7/prd/033-message-metadata-shortcut-crud-and-reviewable-meal-cards.md) 的三个默认快捷按钮与输入区呈现

## 背景

`ConversationSession` 已经保存标题，但当前标题只是首条用户消息清理空白后截取 28 个字符。它能
避免空标题，却不能稳定表达一段对话的主题；纯媒体消息尤其容易只显示「1 张图片」之类弱标题。
历史抽屉也只有选择和删除，用户不能把长期继续的对话改成自己熟悉的名称。

教练输入区的三个快捷按钮已经使用横向列表，达到两个健身房后，场馆入口却另占下一行。两类控件
都是发送前的高频上下文，分行会增加输入区高度并造成视觉断裂。

## 用户结果

1. 首次发送后立即出现本地兜底标题；第一个成功的模型回复落盘后，Soma 在后台自动生成简短、
   有语义的标题，聊天回复和后续 Job 不等待标题请求。
2. 标题生成优先使用已启用且已配置的小模型，失败或不可用时回落标准模型；两档都失败时继续显示
   本地兜底标题，不在聊天里插入错误气泡。
3. 历史抽屉每行提供「重命名」；用户保存的标题跨重启和备份恢复保留，并且永远不被迟到的自动
   生成结果覆盖。
4. 手动标题可通过「恢复自动标题」回到本地兜底，并在已有成功来回时重新异步生成。
5. 快捷按钮与达到两个后的当前健身房入口始终位于同一个横向滚动行；窄屏、长名称和大字号不
   压缩文字、不折到第二行。

## 产品规则

### 标题生命周期

- 新 Session 初始标题为「新对话」。首条用户消息落盘时仍用现有确定性规则即时形成最多 28 字的
  兜底标题，纯媒体使用附件类型摘要。
- 只有成功完成的 ReAct Turn 才触发语义标题请求；纯本机确定性快捷训练继续保持不调用 LLM 的
  产品承诺，只使用兜底标题。
- 生成输入只取该 Session 最早一个成功 user-assistant 来回的可见文字，并分别限制长度；不包含
  媒体 Base64、Tool 参数/结果、Trace、滚动摘要或其他 Session。
- 模型只输出一行标题。App 清理引号、Markdown、标题前缀与多余空白，拒绝空结果，并把最终标题
  限制为 28 个字符。
- 自动标题成功一次后保持稳定，后续 Turn 不自行改写；生成失败时可在下一次成功 Turn 再尝试。
- 改标题和恢复自动标题都不修改 `updatedAt`，不能仅因元数据编辑改变历史会话排序。

### 编辑与单行布局

- Session 行的可见菜单提供「重命名」「恢复自动标题」和「删除对话」；原有尾随左滑删除继续
  保留。「恢复自动标题」只在手动标题下出现。
- 重命名使用系统文本输入弹框。保存前合并换行与连续空白；空标题不可保存，最长 40 个字符。
- 重命名允许发生在 Agent 处理中。异步结果写回前必须重新检查标题来源；若用户已经手动编辑，
  直接丢弃模型结果。
- 快捷按钮和健身房 Menu 共用一个水平 `ScrollView`。附件预览与动作建议仍是独立上下文条，
  不塞入这行，也不改变它们的优先级。
- 菜单、重命名、恢复自动标题和单行横向滚动提供 VoiceOver 可达语义。

## 数据与隐私

- `ConversationSession` 新增可选 `titleSourceRaw`，区分 `fallback`、`generated`、`manual`；旧库
  缺字段按 `fallback` 解释。字段进入数据库结构文档与备份 DTO。
- 标题请求是新增的模型调用，但不增加新的 Provider、账户、服务器事实源或触发用户业务写入。
  只在用户原本已成功发送给所配置模型的 ReAct 来回上触发，优先小模型、回落标准模型。
- 标题内容仍可能包含私人身体主题；它只保存在当前数据空间并随用户主动备份恢复。日志只记录
  调用档位、模型与空工具集合，不记录标题输入全文。

## 明确不在范围

- 不新增修改标题的 Agent Tool，不让模型自行决定何时改名。
- 不批量重写所有旧 Session，也不根据每一轮内容持续漂移标题。
- 不合并、分享或跨设备同步 Session。
- 不改变快捷按钮的工具白名单、健身房选择规则或附件/动作建议行为。

## 验收

- 单测覆盖兜底标题、生成结果清理、小模型优先/标准模型回落、手动编辑优先、恢复自动标题、
  迟到结果拒绝、标题不改变 `updatedAt` 与备份往返。
- 模拟器创建至少两个虚构 Session，确认成功回复后标题异步更新；生成过程中手动改名，确认结果
  不覆盖；重启/切换 Session 后标题保留。
- 浅色、深色、Dynamic Type 与 VoiceOver 下检查重命名菜单和弹框；三个默认快捷按钮与两个
  健身房场景始终为同一横向滚动行，左右滚动可访问全部控件。
- `make check`、`make verify` 通过。

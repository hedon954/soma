# PRD 064：日、周、月总热量缺口

- 状态：已采纳，已实现
- 日期：2026-09-11
- 版本：0.0.23
- 修订自：[PRD 000](../../../prd/000-origin-through-0.0.11.md)（能量卡总缺口与日页底部提示）
- 上游依据：[PRD 061](061-daily-energy-net-training.md)（日消耗使用去重后的训练增量）
- 下游落地：[ADR 0133](../adr/0133-paired-day-total-energy-deficit.md)、[验收](../../../acceptance.md)

## 用户结果

进展日页将圆环底部原有提示合并为「当前热量缺口 xx kcal，仍可摄入 xx kcal」，不增加独立缺口卡片。
缺口数字用橙色，仍可摄入数字用绿色，其余文字保持主题字色；大字号可自然换行。
周/月在图表底部用同样的紧凑提示仅显示累计缺口，不给已结束周期虚构仍可摄入额度。
日页表示所选日，周/月表示周期累计量，不是日均量。原圆环、日均指标与图表继续保留，年页不新增。
当天没有饮食、训练或身体记录时，不渲染空记录容器；能量卡与下方资源入口直接使用正常页面间距。

## 统计边界

- 每日缺口 = 预估总消耗 − 已记录摄入；消耗继续使用静息 × 日常活动系数 + 去重训练增量。
- 日页包括今天当前已记录数据；周/月沿用现有汇总口径，只累计已结束日期。
- 必须先在同一日配对摄入和消耗再累计，不使用来自不同日期集合的两个平均值相减。
- 无饮食记录、已记录饮食仍缺热量、无法估算消耗及未来日期不参与累计；显式记录 0 kcal 有效。
- 周/月提示仅显示缺口数值，不另占一行解释统计日期。完全没有有效日期时显示待估算，不能显示虚假的 0。
- 缺口保留负值，VoiceOver 明确其表示热量盈余；颜色区分两个指标，不评价缺口大小好坏。
- 日页仍可摄入继续用推荐摄入减已记录摄入，含既有目标调整，最低显示 0；不是直接复制缺口。
- 摄入或消耗缺失时缺口显示未记录/待估算，不显示虚假的仍可摄入额度。
- 所有结果仍是基于已记录摄入的估算，不能据此确认饮食记录覆盖了全部实际摄入。

## 数据与验证

仅新增本地派生投影，不新增持久字段、迁移或远程数据流；「能量依据」共用同一日缺口规则。
测试覆盖训练去重、正负/零、缺测、部分餐食、当前日/未来日期、周/月配对累计和年页不新增。
检查浅深主题、小屏、大字号以及空态。运行 `make verify`。

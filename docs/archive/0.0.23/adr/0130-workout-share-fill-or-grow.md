# ADR 0130：分享海报按内容铺满 Pro Max 纸面，超出才加高

- 状态：已采纳
- 日期：2026-09-09
- 维护者：Soma maintainers
- 部分替代：[ADR 0126](0126-workout-share-pro-max-canvas.md) 仅「不再加高纸面」；440×956 基准纸面、白底与橙黄主视觉仍有效
- 上游依据：[PRD 062](../prd/062-workout-share-fill-or-grow.md)
- 后续替代：暂无
- 下游落地：[验收](../../../acceptance.md)

## 背景

0126 把分享图钉在 iPhone 17 Pro Max 画布上，短会话用 `Spacer` 把页脚推到底，明细上方出现大块空白。

## 决策

宽度固定 440 pt，高度至少 956 pt。页面用自定义 Layout：量完页眉、概览、明细和页脚的理想高度后，
剩余空间全部给明细行均分。1–7 个动作逐步收紧字号与间距。紧凑内容仍高于 956 pt 时，画布按内容加高。

明细继续使用 ADR 0119 的动作外卡与合并项内卡：外卡白底细描边，内卡浅灰；内卡按真实宽度换行，
动作名称和左右参数不设截断行数。图像独立于系统分享弹层的主题。

## 未选择的方案

继续用空白垫满 956 pt；任何动作数都加高；按预估行数写死拉伸表而不测量真实子视图。

## 结果

4–7 个动作铺满 Pro Max 竖屏。更长的训练完整可见，只是不再保持手机比例。

## 验证

布局测试覆盖度量收紧；渲染测试断言短会话 440×956、长会话加高。`make verify`。

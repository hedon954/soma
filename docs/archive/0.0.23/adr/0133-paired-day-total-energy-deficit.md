# ADR 0133：热量缺口按同日完整字段配对后累计

- 状态：已采纳，已实现
- 日期：2026-09-11
- 版本：0.0.23
- 上游依据：[PRD 064](../prd/064-progress-total-energy-deficit.md)
- 部分替代：[ADR 0000](../../../adr/0000-origin-through-0.0.11.md)（日、周、月新增总缺口并合入底部提示；圆环、年度和原日均口径保持）
- 下游落地：[验收](../../../acceptance.md)

## 背景

现有周期摄入与消耗分别计算有效日均值，样本日期可能不同；将它们相减再乘周期天数会产生不存在的缺口。
日详情直接用摄入聚合默认值 0 相减，也会把未记录饮食误当作没有进食。

## 决策

在 `ProgressDailyMetrics` 上共享日缺口规则，要求非未来日、有摄入记录且无已知热量缺项、有效消耗估算。
显式记录的零与缺测区分；结果保持符号。`ProgressEnergyDeficit` 对有效日差值求和并保留覆盖天数。
日页使用当前记录，周/月只包含已结束日期，与原周期日均汇总一致；不修改原消耗估算或训练卡热量。

日页以原圆环底部提示承载「当前热量缺口 xx kcal，仍可摄入 xx kcal」，不另加内嵌卡片。
仍可摄入复用推荐目标与已记录摄入的差额，最低为 0；缺口与该额度可能不同，分别用橙色和绿色数字。
周/月在图表底部仅显示累计缺口；已结束周期不展示仍可摄入。资料不足不产生额度。
年页不新增。缺口是估算且基于已记录饮食，资料不足不补零。
已记录餐食字段齐全不代表已记录全部饮食，因此界面不得将它称为真实或完整摄入。

## 结果

用户直接看到日与周期累计缺口，缺测和不完整日期不会人为放大差值；正负值可互相抵消。
当前周/月不包含尚未结束的今天，参与天数可少于历法天数，统计上下文留在派生数据与 VoiceOver，可见提示仅显示缺口数值。
没有新持久字段，渲染、详情和测试共用派生事实。

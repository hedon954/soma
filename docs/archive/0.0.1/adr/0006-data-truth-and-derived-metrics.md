# ADR 0006：缺失值为空，派生指标使用确定性规则

- 状态：部分已替代
- 决策阶段：2026-07-28 至 2026-07-29
- 后续替代：[ADR 0023](0023-ordered-workout-set-evidence.md) 以逐组证据替代标量训练容量

## 背景

健身数据很容易被“合理默认值”污染。模型若自动补 60 秒间歇、训练时长或动作评分，统计看似完整却不再反映用户事实。

## 决策

### 原始字段

- 用户未提供、媒体也无法可靠识别的字段保存为 `nil`。
- UI 不用经验值替代空字段。
- AI 观察与用户事实分开保存。

### 训练容量

训练容量实时由 `组数 × 次数 × 外部重量` 派生。缺少任一字段、数值无效或纯自重没有额外负重时，不进入容量统计。

### 训练热量

使用本地公式：

`kcal = MET × 参考体重(kg) × 时长(h)`

优先使用实际时长。无氧训练缺少时长时，可以用组次、明确间歇和保守动作节奏推算“计算时长”，但必须：

- 只用于热量估算；
- 记录 MET 与计算时长；
- 标记时长来自推算；
- 不回填实际训练时长。

## 未选择的方案

- 让 LLM 直接心算热量：难复现、难测试、相同输入可能变化。
- 为所有空字段填默认值：统计完整但失真。
- 把派生值单独维护为用户事实：修改源记录后容易不同步。

## 结果

所有趋势都可追溯到原始记录。修改训练记录后，容量实时变化；热量估算可以解释依据和不确定性。

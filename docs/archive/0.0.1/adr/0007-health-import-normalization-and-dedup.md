# ADR 0007：外部健康数据先归一化，并使用增量游标去重

- 状态：已采纳
- 决策阶段：2026-07-29

## 背景

Apple 健康、Keep 和 COROS 可能包含与 Soma 重叠的体重、训练和活动能量。直接复制所有数据会产生重复记录，使连续性、训练容量和体重趋势失真。

## 决策

1. Apple 健康是当前唯一直接接入层。
2. 使用只读 HealthKit 权限和 `HKAnchoredObjectQuery` 增量同步。
3. 外部样本转换为现有 `BodyEntry` 或 `WorkoutEntry` 后再参与产品。
4. 每个数据空间、来源和数据流分别保存 anchor/cursor。
5. 每条记录保存外部来源和外部样本 ID，用于幂等去重。
6. 处理 HealthKit 的删除样本，使来源删除可以反映到 Soma。
7. Keep 或 COROS 写入 Apple 健康的数据可经同一通道进入；直接云端接入只有在获得公开合作 API 与 OAuth 凭据后再实现。

## 未选择的方案

- 每次导入最近一年全部数据：实现简单，但重复和删除难以处理。
- 为每个供应商建立平行模型：统计和 CRUD 会分裂。
- 假设 Keep/COROS 私有接口可用：缺少稳定授权基础。

## 结果

同步可以重复执行而不重复计数。任何新外部渠道都必须先定义来源 ID、游标、删除语义和到 Soma 模型的映射。

## 问题

早期本地演示分析器可以展示界面，却不能证明聊天真的具备 Agent 能力。用户需要的是常规、可解释的 ReAct 交互：模型可以自然说话，也可以调用本地工具读取或写入事实，获得工具结果后继续判断，直到完成本次任务。

## Agent 行为

本阶段最初定义每条用户消息启动一条独立 Trace，最多执行八轮；后续
[PRD 006](006-footprints-location-and-retry.md) 已把当前语义修订为“一次远程 Attempt
一条 Trace”，同一 Turn 可以重试：

1. App 发送系统提示词、上下文、用户消息和必要媒体；
2. 通过 OpenAI-compatible API 的 `tools` 字段注册固定工具；
3. 模型流式输出自然语言，或返回一个或多个原生 `tool_calls`；
4. App 执行确定性本地工具；
5. 结果以 `role: tool` 和对应 `tool_call_id` 返回模型；
6. 模型继续回复或调用工具，直至没有新的工具调用。

不要求模型输出自定义“决策 JSON”。结构化记录一律由 Tool Call 完成，而不是从最终自然语言中猜测。

## 模型服务

首批内置五个平台：

- OpenAI；
- DeepSeek；
- 阿里云百炼；
- 火山引擎；
- 腾讯云。

选择供应商后，在对应 API Key 已保存时自动请求最新可用模型列表，以菜单供选择；同时始终允许高级用户手动输入模型 ID。

已知不支持图片/视频的模型应在上传前提示。无法预判时，由供应商实际响应判定，并把可理解的错误原因展示在聊天与执行日志中，不能静默失败或伪装成功。

所有模型调用使用流式接口。当前不展示或持久化 thinking/reasoning 内容。

## 渐进式 Skills

系统先只披露 Skill 目录。模型需要某项专业流程时调用 `load_skill` 读取完整 Markdown：

1. 健身房分析；
2. 用户健身计划制定；
3. 动作分析；
4. 饮食分析；
5. 体态分析；
6. 运动趋势分析；
7. 运动量分析；
8. 运动热量估算。

Skills 可以在高级设置中修改、恢复默认并使用 Markdown 编辑/预览。工具名称、工具描述、参数 Schema 和输出协议是系统安全边界，不允许用户配置，也不需要手工写入系统提示词。

## Trace、Span 与 Event

### Trace

一次远程 Attempt 从开始到最终回复、失败或取消，构成一条完整 Trace。Trace 至少记录：

- 开始/结束时间、总耗时和状态；
- 输入预览、媒体类型与关键帧数量；
- 平台、模型、端点和数据空间；
- 最终结果或清晰错误；
- Token 用量；
- 有序 Span 时间线。

### Span

Span 类型包括：

- `model`：一次模型推理；
- `skill`：一次渐进式 Skill 加载；
- `tool`：一次本地工具执行；
- `output`：最终完成、失败或取消。

每个 Span 可以包含名称、状态、相对时间、耗时、输入、输出/错误和运行元数据。成功和失败使用清晰但克制的视觉层级。

### Event

Span 不是结束后一次性生成的静态报告。模型文本增量、Span 开始、Span 更新、Span 结束和 Trace 完成都是实时 Event，UI 应边执行边渲染。

聊天页把一次 Agent Turn 渲染为有序异构 Event Cards：

- 自然语言输出是独立文字卡；
- Skill 和 Tool 是与文字同级的操作卡；
- 连续文字 delta 按稳定 Item ID 合并；
- Skill/Tool 生命周期按稳定 Span ID 更新同一张卡；
- Skill/Tool 之后的文字必须创建新卡，保留真实执行顺序；
- 失败保留此前成功卡片，并追加错误卡。

所有卡片在执行结束、页面切换和重新进入聊天后继续保留。普通聊天只展示名称、状态和简要结果；完整输入、输出、耗时、Token 与错误上下文留在开发者执行日志，避免干扰主对话。

当前不要求失败重试。失败必须完整落盘并可审查。

## 安全与隐私

- Tool 没有任意代码执行能力。
- Agent 不获得数据库句柄、API Key、Authorization 头或本地文件路径。
- 日志不保存媒体 Base64。
- 已成功执行的本地写入不会因最终自然语言回复失败而回滚。
- 同一 Trace 中重复的写入调用必须去重。
- Tool 错误作为工具结果返回给模型，使其有机会解释或修正。

## 开发者能力

高级设置容纳低频能力：

- 可编辑角色与安全策略提示词；
- 八项 Skills 的 Markdown 编辑和预览；
- 执行日志列表与 Trace 详情；
- 演示/个人数据空间切换。

工具与输出格式不属于可编辑内容。

# ADR 0123：动作库去掉受力肌群轴，模式改为类型

- 状态：已采纳
- 日期：2026-09-07
- 维护者：Soma maintainers
- 上游依据：[PRD 057](../prd/057-coach-focus-progress-rings-and-library-clarity.md)
- 部分替代：[ADR 0000](../../../adr/0000-origin-through-0.0.11.md) 的三条分类轴与原始模式标签侧栏；部位映射、餐次配色与「不改写元数据」不变
- 后续替代：暂无

## 背景

「受力肌群」与「身体部位 → 主要肌群」重叠。侧栏把目录里每条原始动作模式都摊开，出现膝伸、
肘屈、器械孤立等几十项，浏览成本高于筛选价值。

维护者建议改成有氧、HIIT、运动表现、复合、孤立、核心。其中 HIIT 与有氧不是互斥能量系统，
仓库也没有 HIIT 字段；「运动表现」过宽，会和复合力量重叠。因此不用那份清单当真值。

## 决策

- 侧栏只保留「全部动作」「身体部位」「动作类型」。部位及下级主要肌群不变。
- 动作类型是封闭枚举，由现有 `movementPatterns` 确定性映射，不写回动作定义：
  - 复合力量：蹲、铰链、弓步、推、拉、负重行走、全身等
  - 孤立训练：关节级伸屈／外展内收、各部位「孤立」标签
  - 核心：躯干屈曲、旋转、抗旋转、抗伸展、核心稳定
  - 爆发表现：爆发、三关节伸展
  - 有氧体能：体能
  - 未标注：没有任何可映射标签
- 一个动作可落入多个类型。搜索仍只匹配标准名，并与当前分类取交集。
- 搜索框移到右侧列表上方，宽度与卡片对齐；左侧列表从导航栏下顶满高度。
- 不增加器械、难度或 HIIT 猜测。

## 未选择的方案

- 按有氧／HIIT／表现切分：缺字段，类别正交性差。
- 继续展示原始标签：侧栏不可读。
- 删掉类型轴只留部位：推／拉／蹲这类意图会找不到。

## 结果

### 正向影响

- 分类更短，搜索不再压住侧栏。

### 成本与限制

- 自定义生僻标签会进未标注，用户仍可用名称搜索。

## 验证

`ExerciseLibraryFilterTests` 覆盖映射、多类型、未标注和部位主要肌群。`LibraryAndMealsUITests`
更新分类标识。`make verify`。

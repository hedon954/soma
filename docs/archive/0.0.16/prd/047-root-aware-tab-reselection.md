- 日期：2026-08-26
- 修订自：[PRD 000](../../../prd/000-origin-through-0.0.11.md) 的底部 Tab 再选规则
- 后续修订：[PRD 052](../../0.0.19/prd/052-coach-training-and-lifecycle-reliability.md) 增加“单击保持 no-op、仅系统双击回到 AI 消息尾部”的子行为

## 背景

现有规则把再次点按当前 Tab 一律解释为“回根”。这会让已经在根页的点击产生没有用户价值的
状态写入；教练 Tab 还会收起当前上下文并强制滚动，打断正在阅读的消息。Tab 再选必须只在确有
导航层级需要退出时产生结果。

## 用户结果

1. 已在教练 Tab 时，再次点按「教练」不关闭会话抽屉或健身房页、不改变滚动位置，也不重建对话。
2. 已在训练、进展或设置的根页时，再次点按当前 Tab 不产生任何变化。
3. 训练、进展或设置停在详情页时，再次点按当前 Tab 才返回该 Tab 根页。
4. 在不同 Tab 间切换继续保留各自导航栈，普通切换不触发回根。

## 产品规则

- “根页”指当前 Tab 的导航栈没有推入详情；Sheet、输入草稿和滚动位置不因根页再选而重置。
- 教练再选始终是 no-op，不以其内部抽屉、健身房页或滚动位置判断回根。
- 训练、进展、设置只有在当前导航栈明确非根时才重置该 Tab 的栈身份。
- 一次点击最多产生一个确定性效果：切换、非根回根或无操作。

## 数据与隐私

- 不改变业务数据、SwiftData schema、媒体、凭据或远程发送内容。
- 根状态只存在于当前界面生命周期，不持久化、不写日志中的用户内容。

## 明确不在范围

- 不改变切换到教练 Tab 时既有的最新消息定位。
- 不把根页再选改造成滚到顶部、刷新、关闭 Sheet 或其他快捷操作。
- 不改变四个 Tab 的顺序、图标和独立导航栈。

## 验收

- 单元测试覆盖普通切换、四个根页再选、教练非根再选和三个非教练 Tab 非根再选。
- 模拟器验证教练再选保持滚动与分页，设置详情再选返回设置根页。
- 静态门禁禁止恢复教练再选通知或无条件重建非教练 Tab。
- `make check`、`make verify` 通过。

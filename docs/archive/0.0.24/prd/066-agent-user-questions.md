## 用户结果

Agent 缺少必要事实、需要选择或确认时，调用 `ask_user_questions` 展示 1–3 个问题，每个选项按钮独占一行。
按钮文字是用户口吻的完整句子，点击立即发送。未绑定操作的选项按普通用户输入运行 Agent；
已绑定且参数确定的选项直接调用现有本地工具，产生同样的 Job、Trace、Event 和结果卡。
选项不足时可提供自定义输入框，发送后按普通用户输入处理。

用户发送任何新消息，包括附件、其他问题、按钮或自由输入后，当前推荐问题收起；历史保留问题语义。
旧按钮、跨会话按钮和重复点击不得产生副作用。失败保持可重试，不伪装成功。
已经授权且事实明确的请求直接执行，不为使用新能力重复确认。

## 验收

普通按钮、自定义回答等同正常聊天；确定性按钮在无 API Key 时仍能执行且不调用模型。
校验绑定工具权限、参数、幂等、重启后的提问与失效、迟到提问，以及浅深主题、长文本、键盘和大字号。
执行 `make check`、`make verify`。不增加新数据库字段或任意代码执行。

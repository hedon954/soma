## 用户结果

连接 Apple 健康后，Soma 在个人空间自动读入体重（`bodyMass`）与体脂率（`bodyFatPercentage`），按本地自然日各保留一条健康记录：当天各指标取最后一次有效样本组成日摘要，较晚更新覆盖该指标，但不因只同步到其中一项而抹掉另一项。
列表按所选时间区间平铺记录，取消日卡、条数与折叠；日期只在行内出现一次。每一条健康记录天然代表一天，手动记录同日可并存且不被健康同步删除。行内用统一尺寸的来源/占位图标容器显示来源（例如官方 Keep）或手动记录；同日多来源须如实展示，不谎称全来自单一品牌。
「体重记录」页（导航栏 inline 小标题，非 large 大标题）以**一张合并趋势图**同时展示体重与体脂率（共享所选时间域；左轴 kg、右轴 %；不同颜色/线型/点形；无指标切换）；提供一周／一个月／三个月／一年区间选项，**默认一个月**，锚定真实「现在」的日历窗而非最新记录日；区间同时筛选趋势图和列表。轴单位在各自轴顶端横向显示；曲线与点保持细线低噪声。明细按指标分别展示真实采样时间与来源，不把同日不同时间伪称同一次测量。身体记录用户路径不展示也不再输入腰围；已有腰围字段仍保存在 `BodyEntry`。

## 产品规则

- 新增只读 `bodyMass` 与 `bodyFatPercentage`。不读取 BMI、瘦体重、身高样本，也不同步腰围健康类型。
- 授权仍由现有「连接 Apple 健康」触发；写入类型为空；授权结束不表示已获准读取。已连接用户新增体脂权限后需再次走授权/系统设置补开；本 App 无法区分读权限拒绝与暂无样本。
- 自动同步触发：已连接个人空间的冷启动、回前台、连接成功后立即追赶；可选注册观察者以尽力后台唤醒。不宣称 iOS 实时后台保证。体重与体脂各自游标、删除感知与 generation 守卫。
- 健康导入按自然日写入一条 `BodyEntry`：`externalID=bodyDay:<yyyy-MM-dd>`；各指标保留获胜样本的 UUID、时间与来源。增量游标仍按样本流；幂等覆盖；不覆盖、不删除用户/教练手动记录，也不把手动记录按天压缩。
- 当天各指标独立取最后有效样本。仅体重或仅体脂的日记录均合法；后到的单指标不得清空另一指标。纯体脂导入不得改写最新体重取值逻辑（最新体重仍只看有体重值的记录）。健康导入只读，不得编辑覆盖。详情须能区分各指标的真实时间与来源。
- HealthKit 体脂常用 `.percent()`（1.0 = 100%），入库为 0…100 的百分点；无效域丢弃。
- 保留 `HKSourceRevision` 的 `source.name` 与 `bundleIdentifier`；已知映射（Keep、Apple 健康等）+ 未知回退。Keep 使用 App Store 官方发行页图标（不自绘仿制；不声称开放许可）；主行简洁来源名，归属说明在品牌文档。
- 列表行：来源图标与手动占位共用同一容器尺寸、圆角、内边距与基线。
- 「体重记录」页：一张合并图，体重用身体蓝细实线、体脂用对比色细虚线（可区分点形，密集时可减少常驻点、选中时突出）；共享**所选**时间域，左轴 kg、右轴 %（单位置于各轴顶端横向，不竖排旋转、不与刻度/图例重叠；不混用单一刻度、不隐藏归一化）；缺测不编造、不插值；默认无图下读数；用户点选图上样本后，在图内浮层展示**该次**指标、真实单位与样本时间，不把不同时间指标拼成一次测量。行摘要可含体脂百分点；身体记录用户路径不展示腰围。
- 趋势图与列表共用时间区间：一周、一个月、三个月、一年（中文选项）；默认一个月；窗口相对可注入的「现在」按日历起算（半开区间），不以最新样本日期冒充今天；过滤在查询层完成，不漏窗内较早记录，也取消列表全量与日卡分组。
- 当前体重与训练热量等消费方取「有体重值的最新一条记录」（含健康导入）；不把健康导入写成用户口头事实。
- 健康导入的身体记录不进入教练模型上下文批量历史、不进入应用备份/导出与 Server；内部回滚快照可保留。手动记录规则不变。
- 断开连接停止同步并保留已导入记录；清空个人数据删除记录；用户在 Apple 健康删除某日最后有效样本后，同步回退到该日上一有效样本，该指标已空则只清空该指标，两指标都空才移除该日健康记录。拒权或空结果不得擦除本地健康日记录。
- 演示空间不读真实健康库。

## 数据与隐私

`BodyEntry` 可选最初来源名称与 bundle 字段；旧库为 nil。SwiftData 轻量加字段，不重建。腰围字段既有值保留。体重与体脂导入共用 `externalSource=appleHealth`，产品记录以 `externalID=bodyDay:<yyyy-MM-dd>` 标识自然日；各指标证据保存在日记录上。旧的 `bodyMass:` / `bodyFat:` 样本行被幂等折叠进日记录后删除，手动行保留。
个人库 complete 保护并排除系统备份。健康导入属于可再同步的健康事实。

## 明确不在范围

- 写回 Apple 健康；厂商云 API；从私有 API 抓取已安装 App 图标。
- 同步 BMI/瘦体重/身高/腰围健康样本；用户路径不展示或输入腰围。
- 把同日不同时间的体重与体脂伪称为「同一次测量」，或在多来源时使用单一品牌图标。
- 宣称能判定 HealthKit 读权限被拒；TestFlight/发版、账号与云同步。
- Keep 是否一定写入真实体脂无法从源码保证；只同步实际可读样本。真机 Keep→健康→Soma 对照另记。

## 验收

- 连接后按自然日各保留一条健康记录；同日多次只保留各指标最后有效样本；重复同步不产生重复日行；手动记录与导入共存且不被覆盖。
- 列表 Keep/未知/手动行图标容器尺寸与对齐一致；Keep 为官方发行页图标原色；多来源不谎称 Keep；主行不堆许可声明；无障碍称「Keep 来源」。
- 合并单图双轴、无指标 Tab；可选一周／一个月／三个月／一年（默认一个月）；共享所选时间域并同时筛选列表；图按日取各指标最后一次；仅体重/仅体脂/稀疏/空窗表现正确；轴单位顶端横向；细线低噪声；点选 inset 浮层展示该指标真实时间（SpatialTap，不拦滚动）；大字号图例/列表上下布局无日期竖排，体重「N kg」足宽整行，体脂率标签与「N%」可上下排且不拆不截；列表无日卡/条数/折叠，日期只在行内一次；超大字号可滚到末行并完整高于浮动 Tab；夹具含腰围时任何身体记录用户路径都不出现腰围输入或展示。
- 0…1 HealthKit 体脂正确转为百分点；纯体脂样本不抹掉最新体重；删除当日最新样本后回退到上一有效样本。
- 健康导入不进入备份/导出与教练批量身体历史；最新体重仍可供本机计算。
- `make verify` 通过；真机授权、后台唤醒与真实旧库升级另记。

# PRD 080：Apple 健康体重与体脂同步及身体指标曲线

- 版本：未发布

- 后续修订：暂无
- 下游落地：[ADR 0149](../adr/0149-healthkit-body-mass.md)、[验收](../acceptance.md)、[工程原则](../../CLAUDE.md)、[数据库结构](../engineering/database-schema.md)

## 用户结果

连接 Apple 健康后，Soma 在个人空间自动读入体重（`bodyMass`）与体脂率（`bodyFatPercentage`），各自写入本地身体记录。
列表每一行用统一尺寸的来源/占位图标容器显示最初来源（例如 Keep）或手动记录；导入与手动行布局一致，仅靠字形区分。
「体重记录」页（导航栏 inline 小标题，非 large 大标题）以**一张合并趋势图**同时展示体重与体脂率（共享所选时间域；左轴 kg、右轴 %；不同颜色/线型/点形；无指标切换）；提供一周／一个月／三个月／一年区间选项，**默认一个月**，锚定真实「现在」的日历窗而非最新记录日；区间只裁剪趋势图，不隐藏下方历史列表。轴单位在各自轴顶端横向显示；曲线与点保持细线低噪声。本页不展示腰围。已有腰围字段仍保存在 `BodyEntry`。

## 产品规则

- 新增只读 `bodyMass` 与 `bodyFatPercentage`。不读取 BMI、瘦体重、身高样本，也不同步腰围健康类型。
- 授权仍由现有「连接 Apple 健康」触发；写入类型为空；授权结束不表示已获准读取。已连接用户新增体脂权限后需再次走授权/系统设置补开；本 App 无法区分读权限拒绝与暂无样本。
- 自动同步触发：已连接个人空间的冷启动、回前台、连接成功后立即追赶；可选注册观察者以尽力后台唤醒。不宣称 iOS 实时后台保证。体重与体脂各自游标、删除感知与 generation 守卫。
- 每条 HealthKit 样本对应一条 `BodyEntry`：体重 `externalID=bodyMass:<sampleUUID>`，体脂 `externalID=bodyFat:<sampleUUID>`；幂等覆盖同一样本；不覆盖用户/教练手动记录。
- **不**因同日、同来源或相近时间把体重样本与体脂样本捏成同一条记录；仅体重或仅体脂的导入行均合法。纯体脂导入不得清空或改写当前体重取值逻辑（最新体重仍只看有体重值的记录）。
- HealthKit 体脂常用 `.percent()`（1.0 = 100%），入库为 0…100 的百分点；无效域丢弃。
- 保留 `HKSourceRevision` 的 `source.name` 与 `bundleIdentifier`；已知映射（Keep、Apple 健康等）+ 未知回退。Keep 使用 App Store 官方发行页图标（不自绘仿制；不声称开放许可）；主行简洁来源名，归属说明在品牌文档。
- 列表行：来源图标与手动占位共用同一容器尺寸、圆角、内边距与基线。
- 「体重记录」页：一张合并图，体重用身体蓝细实线、体脂用对比色细虚线（可区分点形，密集时可减少常驻点、选中时突出）；共享**所选**时间域，左轴 kg、右轴 %（单位置于各轴顶端横向，不竖排旋转、不与刻度/图例重叠；不混用单一刻度、不隐藏归一化）；缺测不编造、不插值；默认无图下读数；用户点选图上样本后，在图内浮层展示**该次**指标、真实单位与样本时间，不把不同时间指标拼成一次测量。行摘要可含体脂百分点；不展示腰围。
- 趋势图时间区间：一周、一个月、三个月、一年（中文选项）；默认一个月；窗口相对可注入的「现在」按日历起算（半开区间），不以最新样本日期冒充今天；仅过滤图内点，列表仍展示全部已加载记录。
- 当前体重与训练热量等消费方取「有体重值的最新一条记录」（含健康导入）；不把健康导入写成用户口头事实。
- 健康导入的身体记录不进入教练模型上下文批量历史、不进入应用备份/导出与 Server；内部回滚快照可保留。手动记录规则不变。
- 断开连接停止同步并保留已导入记录；清空个人数据删除记录；用户在 Apple 健康删除样本后，后续同步删除对应导入记录。
- 演示空间不读真实健康库。

## 数据与隐私

`BodyEntry` 可选最初来源名称与 bundle 字段；旧库为 nil。SwiftData 轻量加字段，不重建。腰围字段既有值保留。体重与体脂导入共用 `externalSource=appleHealth`，以 `externalID` 前缀区分指标。
个人库 complete 保护并排除系统备份。健康导入属于可再同步的健康事实。

## 明确不在范围

- 写回 Apple 健康；厂商云 API；从私有 API 抓取已安装 App 图标。
- 同步 BMI/瘦体重/身高/腰围健康样本；本页不展示腰围。
- 把不同时间/来源的体重与体脂强行配成「同一次测量」。
- 宣称能判定 HealthKit 读权限被拒；TestFlight/发版、账号与云同步。
- Keep 是否一定写入真实体脂无法从源码保证；只同步实际可读样本。真机 Keep→健康→Soma 对照另记。

## 验收

- 连接后追赶导入体重与体脂；重复同步不产生重复样本行；手动记录与导入共存；体重与体脂样本独立。
- 列表 Keep/未知/手动行图标容器尺寸与对齐一致；Keep 为官方发行页图标原色；主行不堆许可声明；无障碍称「Keep 来源」。
- 合并单图双轴、无指标 Tab；可选一周／一个月／三个月／一年（默认一个月）；共享所选时间域；图按日取各指标最后一次；仅体重/仅体脂/稀疏/空窗/同日多次表现正确；轴单位顶端横向；细线低噪声；点选 inset 浮层；大字号图例/列表上下布局无日期竖排；列表日卡分组且末行不被 Tab 遮挡；夹具含腰围时本页不出现腰围；区间切换不隐藏列表。
- 0…1 HealthKit 体脂正确转为百分点；纯体脂样本不抹掉最新体重。
- 健康导入不进入备份/导出与教练批量身体历史；最新体重仍可供本机计算。
- `make verify` 通过；真机授权与后台唤醒另记。

# PRD 079：每日目标热量缺口

- 状态：已实现；模拟器验证通过；真实旧库升级待验收
- 日期：2026-11-07
- 版本：未发布
- 修订自：[PRD 078](078-residual-energy-coefficient.md)（补充摄入目标设置，不改变总消耗）
- 下游落地：[ADR 0148](../adr/0148-daily-target-deficit.md)、[验收](../acceptance.md)

## 用户结果

减脂用户可以在「设置 → 身体信息 → 健身目标」下修改每日目标热量缺口，默认 400 kcal。
保存后重新打开仍保留；进展中的推荐摄入和仍可摄入使用相同偏好，教练上下文说明这是用户设置。

## 规则

- 只对减脂目标生效；增肌、增肌减脂和未选择目标保持已有规则。
- 推荐摄入 = max(0, 预估总消耗 − 每日目标热量缺口)。
- 仍可摄入 = max(0, 推荐摄入 − 已记录摄入)。
- 接受有限非负数，包括显式 0；空白、负数、非数字和非有限数不能保存，并显示纠正提示。
- 缺少消耗估算时不生成摄入目标。摄入超过推荐时仍可摄入为 0。
- 切换目标不会删除偏好，再切回减脂继续使用；偏好不是医学建议或经校准的身体事实。
- 实际热量缺口仍是预估总消耗减已记录摄入，不能与用户设置的目标缺口混淆。

## 数据与验收

本地个人资料新增可选数值，旧库和旧备份保持 nil，读取回退 400。备份恢复保留自定义值和 0。
不改变静息、残差系数、日活动择优、训练去重和历史健康事实，不新增权限、网络请求或 Agent Tool。

确定性验收覆盖默认、自定义、0、超大目标归零、非减脂不变、缺估算、资料备份和磁盘重开、
进展投影与教练上下文；设置保存重开提供 UI 回归。iOS 测试必须在 Xcode 环境执行。

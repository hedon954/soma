## 产品是什么

Soma 是无账户、本地优先、聊天驱动的 iOS 私人身体智能。路径固定为：

```text
自然表达 → 流式 ReAct → 确定性工具 → 可审查记录 → 长期趋势
```

最低系统 iOS 17。四个 Tab 为教练、训练、进展、设置，各自保留导航栈。不提供账户、云端身体
数据库或医疗诊断。

## 用户结果

1. 用文字、照片、视频和语音向教练陈述事实；训练计划可在专用 GUI 编排，但与聊天共用同一数据
   与验证边界。
2. AI 写入的训练、饮食、身体、健身房记录都能回看、编辑和删除；未提供的字段保持为空。
3. 缺少 API Key 时消息仍落盘暂存，恢复后按 FIFO 补偿，不丢用户输入。
4. 可从动作库组建当前训练计划，一步开始带练；倒计时只取景，开组后放大录制，计划结束立即分享
   并回到训练主页。
5. 可选远程持续执行默认关闭；业务记录仍由本机固定 Tool 审查落地。
6. 演示与个人数据空间隔离；导出、加密备份与个人清除可用。

## 产品规则

### 教练与会话

- 聊天是非结构化事实的默认创建路径。输入区只保留加号、文本、语音和发送。
- Session 按自然日解析；用户可继续旧会话、长按标题改名、左滑删除该会话聊天图，不删除业务记录。
- 成功来回后可异步生成标题；手动标题优先。消息底部单行时间，用户消息可带位置。
- 快捷按钮完整 CRUD，各自持有工具白名单；未选按钮时注册当前协议全部 Tool，选中后只注册白名单。
  Skill 只提供专业方法，不是动态工具。
- AI 正文用本地受控 Markdown；记录卡跟在产生它的步骤之后。饮食原位审查分为可编辑菜品清单与
  只读派生汇总。
- 有序混合媒体贯穿聊天、Agent 与审查；点击进入只读全屏。

### 记录真值

- 缺失值为 `nil`，不补常见值。容量只使用完整有效的组数 × 次数 × 外部重量。
- 热量用本地 MET；推算时长只用于热量并保留推算标记。
- 训练、饮食、身体的 create 每次新增；纠正只走 update。业务身份为本机 Int64。
- 菜品与整餐可空总糖；证据足够时可成对保存升糖速度与依据，不冒充个体血糖预测。
- 外部健康数据经用户授权的 Apple 健康读取，先归一化再用外部 ID 与游标去重。

### 训练计划与带练

- 动作有稳定身份与内置内容；侧别和按次数/按时长归动作定义。计划只保留当前状态，不维护业务
  版本链；已开始 Session 使用不可变处方快照。
- 计划动作用独立逻辑组保存类型、目标、重量与备注；计划组间歇与左右换侧间歇归动作配置，开始
  Session 时才编译到逻辑组。最后一组不生成组间歇，实际休息证据仍逐组保存。
- 带练确定性状态机：一步选择录像策略，计时/休息自动推进，动作记录先于 Session 完成。
- 倒计时小窗取景，开组后放大录制；预览与历史缩略 aspect fill。相机完整 activation 有界，
  预览宿主所有权、朝向锁定与失败可见性必须保留。
- 计划总览保留动作库主要/辅助肌群身份。专属离线动作图不少于 100。

### Agent

- 原生流式 Tool Calling；Tool Schema 系统所有，不能被用户提示词覆盖。
- 发送先原子保存 Turn、媒体、上下文与 Job。同气泡 step 检查点续跑不递增 attemptNumber。
- 活动执行预算与业务时间解耦；等待用户、网络或前台不计时。0.0.9 收口时文字/图片/视频总预算
  固定为 3/5/10 分钟（0.0.12 改为可配置，见 PRD 043）。首增量门禁 20/40/60 秒。
- 明确欠费只由用户释放，后续消息受 FIFO 屏障。网络/供应商在 Loop 外仍可自动补偿
  （0.0.11 改为可见失败后一律人工恢复，见 PRD 042）。
- 本机与远程使用设备生成的版本化模型输入；远程进入 `waitingForDevice` 等本机执行固定 Tool。
- 十轮外对话在 Loop 前滚动压缩，可审查、可回退。

### 界面与系统入口

- 频率优先的黑白双主题；彩色只用于语义图标与数据。再点已选 Tab 回到该 Tab 根页面。
- 进展把近 7 天、连续性和容量收在一张分段卡；最近活动默认最多 6 条并提供训练、饮食历史入口。
- 全产品 Switch 使用系统外形和统一开启状态色，浅深主题均能辨认，且不能只靠颜色表达状态。
- 免费签名阶段 Widget 只提供静态快速记录与锁屏入口，不使用 App Groups。
- 设置页末端可直接发送应用内反馈；个人阶段经本机 QQ SMTP 投递到固定维护者邮箱。

## 数据与隐私

- 业务库、原始媒体和用户 API Key 默认留在设备；Keychain 为 ThisDeviceOnly。
- 远程执行需一次性明确授权；服务器不是身体业务事实源。
- 测试、日志、Issue 不得含真实身体照片、健康记录或密钥。

## 明确不在范围

- 账户系统、云同步身体库、任意代码工具、展示模型 thinking。
- 情境化动态主屏组件（暂缓，待 App Groups Team）。
- 把 Keep/COROS 做成独立直连（无稳定授权时只走 Apple 健康）。

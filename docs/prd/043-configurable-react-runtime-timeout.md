# PRD 043：可配置 ReAct 运行超时

- 状态：已采纳，已实施；待真机界面验收
- 日期：2026-08-25
- 修订自：
  - [PRD 004](004-soma-current-product.md) 的 Agent 分层超时基线
  - [PRD 028](028-retry-active-runtime-budget.md) 的固定 3/5/10 分钟活动执行预算
- 后续修订：暂无
- 上游依据：维护者明确要求把运行超时与 ReAct 步骤上限放在一起配置
- 下游落地：[ADR 0098](../adr/0098-user-configurable-react-active-runtime-timeout.md)

## 背景

ReAct 步骤上限已经可以在高级设置调整，但整轮活动执行预算仍固定为文字、图片、视频
3/5/10 分钟。复杂任务即使没有达到步骤上限，也可能被固定时间强制报错；用户无法根据模型速度、
任务复杂度和费用偏好调整这一边界。

## 用户结果

1. 「高级设置 → ReAct 循环」同时显示步骤上限和运行超时上限。
2. 默认「自动」继续使用文字/图片/视频 3/5/10 分钟，不改变升级后的既有行为。
3. 用户可把超时改为 3–60 分钟；自定义后文字、图片和视频使用同一个明确上限。
4. 恢复默认设置同时恢复 100 步和自动超时。
5. 超时错误继续保留当前回复、检查点和已经成功的 Tool；用户可调整设置后手动重试未完成步骤。

## 产品规则

- 超时只累计 Job 真正处于本地活动执行的时间；等待用户、网络、前台或设备不计时。
- 用户显式重试刷新活动执行窗口，并读取当时最新的超时设置；自动恢复继续扣除已消耗时间。
- 正在执行的窗口不因设置页变化而中途改写 deadline；新执行或下一次手动重试使用新值。
- 运行超时不能关闭，也不提供无限执行；自定义范围固定为 3–60 分钟。
- 首增量 20/40/60 秒门禁、ReAct 内部三次退避和步骤上限保持独立。

## 数据与隐私

- 配置只保存在本机 `UserDefaults`，不新增 SwiftData 字段或数据库迁移。
- 远程执行只在既有版本化模型输入中携带生效后的秒数；不新增身体数据、聊天内容或凭据出网。
- 恢复默认会删除自定义超时值，不影响 Session、Job、Trace、检查点或业务记录。

## 明确不在范围

- 不取消整轮执行预算，不允许无限运行。
- 不改变首增量门禁、Provider 网络超时、服务器保留期限或任务重试次数。
- 不重跑已经成功的模型或 Tool 步骤。

## 验收

- 默认空配置读取自动模式，3/5/10 分钟预算保持不变。
- 自定义 17 分钟后，本地整轮预算与远程模型输入中的三类总时限均为 1,020 秒。
- 小于 3 或大于 60 的值分别收敛到边界；恢复默认后回到自动模式。
- 设置页浅色、深色和较大 Dynamic Type 下两行 Stepper、中文说明与恢复按钮均可完整滚动和操作。
- `make check`、`make verify` 通过；真机使用虚构任务确认调整后下一次手动重试采用新预算。

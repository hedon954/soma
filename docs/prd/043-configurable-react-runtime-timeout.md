## 背景

ReAct 步骤上限已经可以在高级设置调整，但整轮活动执行预算仍固定为文字、图片、视频
3/5/10 分钟。复杂任务即使没有达到步骤上限，也可能被固定时间强制报错；用户无法根据模型速度、
任务复杂度和费用偏好调整这一边界。

## 用户结果

1. 「高级设置 → ReAct 循环」同时显示步骤上限和运行超时上限。
2. 默认继续使用文字/图片/视频 3/5/10 分钟，不改变升级后的既有行为。
3. 用户可分别把文字、图片和视频超时改为 3–60 分钟；默认分别为 3/5/10 分钟。
4. 恢复默认设置同时恢复 100 步与三类默认超时。
5. 超时错误继续保留当前回复、检查点和已经成功的 Tool；用户可调整设置后手动重试未完成步骤。

## 产品规则

- 超时只累计 Job 真正处于本地活动执行的时间；等待用户、网络、前台或设备不计时。
- 用户显式重试刷新活动执行窗口，并读取当时最新的超时设置；自动恢复继续扣除已消耗时间。
- 正在执行的窗口不因设置页变化而中途改写 deadline；新执行或下一次手动重试使用新值。
- 运行超时不能关闭，也不提供无限执行；自定义范围固定为 3–60 分钟。
- 首增量 20/40/60 秒门禁、ReAct 内部三次退避和步骤上限保持独立。

## 数据与隐私

- 配置只保存在本机 `UserDefaults`，不新增 SwiftData 字段或数据库迁移。
- 远程执行只在既有版本化模型输入中携带生效后的秒数；不新增身体数据、聊天内容或凭据出网。
- 恢复默认会把三类值重置为 3/5/10 并删除旧统一值，不影响 Session、Job、Trace、检查点或业务记录。

## 明确不在范围

- 不取消整轮执行预算，不允许无限运行。
- 不改变首增量门禁、Provider 网络超时、服务器保留期限或任务重试次数。
- 不重跑已经成功的模型或 Tool 步骤。

## 验收

- 默认空配置读取 3/5/10 分钟预算。
- 分别设置 3、17、60 分钟后，本地整轮预算与远程模型输入中的三类总时限分别为 180、1,020、3,600 秒。
- 小于 3 或大于 60 的值分别收敛到边界；旧统一值首次读取时作为三类兼容回退，新设置保存后移除旧值。
- 设置页浅色、深色和较大 Dynamic Type 下三行 Stepper、中文说明与恢复按钮均可完整滚动和操作。
- `make check`、`make verify` 通过；真机使用虚构任务确认调整后下一次手动重试采用新预算。

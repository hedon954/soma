# PRD 065：训练历史倒序与会话分页缓存

- 状态：已采纳
- 日期：2026-09-12
- 修订自：[PRD 000](000-origin-through-0.0.11.md) 的进展明细和会话浏览
- 下游落地：[ADR 0134](../adr/0134-session-history-page-cache.md)

## 用户结果

- 进展「月」「年」训练记录按日期倒序，同一天按发生时间倒序。趋势图仍按时间正序，日、周和身体记录顺序不变。
- 教练历史列表首次只查 14 个 Session，点击「加载更早对话」再查下一页 14 个；不足一页显示实际数量。
- 已加载会话保留在内存，重新打开抽屉、切 Session 和切 Tab 不重新查询历史页。
- 新建、继续发送、改名、删除同步到列表；分页不因插入、时间更新或删除产生重复和漏项。
- 空库显示新建提示；读取失败可重试且保留此前页面。切数据空间必须隔离缓存。

## 数据与隐私

只查询本地数据库，不新增持久字段、迁移或网络请求。缓存与进程同寿命，重启后从第一页开始。

## 验收

确定性测试覆盖月/年及同日顺序、图表顺序保留、14/28/尾页、同时间戳、新建修改删除、缓存复用和空间隔离。
模拟器检查浅深主题、加载更早、抽屉开关和 Tab/Session 往返，运行 `make verify`。

# PRD 081：总消耗把训练列表消耗直接加入

- 状态：已实现，模拟器验收通过
- 日期：2026-11-12
- 版本：0.0.36
- 修订自：[PRD 000](000-origin-through-0.0.11.md)（日活动与总消耗）
- 后续修订：暂无
- 下游落地：[ADR 0151](../adr/0151-training-energy-in-total.md)、[BUG 0068](../bugs/0068-health-activity-cancels-lifestyle-baseline.md)、[验收](../acceptance.md)、[工程契约](../../CLAUDE.md)

## 背景

0.0.32 起，预估总消耗 = 当日静息 × 残差系数 + 所选日活动能量。为避免与 HealthKit 日活动能量重复，已记录的 Soma 训练估算在存在日活动读数时不进入总量，明细也不把训练列表的消耗另列一项。用户在进展日页看到训练记录各自有估算消耗，但总消耗弹层只有静息、基准额外消耗和活动消耗，明确要求训练消耗像活动消耗一样直接加入总量。

## 用户结果

选定日的预估总消耗、推荐/剩余摄入、实际差额、周月年进展与教练上下文使用同一套计算：

```text
当日静息 × 残差系数 + 所选日活动能量 + Soma 已记录训练消耗
```

消耗详情出现独立的「训练消耗」项，数值与当日训练列表的汇总口径一致。增加、编辑或删除训练后，总量和明细随之更新。没有训练时该项为 0，而不是「未记录」。

## 产品规则

- 残差系数、基准额外消耗 = 静息 ×（系数 − 1）、所选日活动能量的既有规则保持不变。日活动仍只取择优后的一份整包；没有读数不编造成 0；显式 0 仍有效；缺少静息时不生成总消耗。
- 「Soma 已记录训练消耗」只汇总进展页训练列表会展示的记录：运动记录且不是日常活动。按各条在列表上展示的估算消耗（`estimatedCalories`）相加，不改用净活动能量或从毛消耗里扣静息。
- 同一条训练记录只计一次。日常活动记录不进入这项，以免与所选日活动能量重复。
- 无训练记录时训练消耗为 0。某条缺少估算、或数值非法（非有限、小于 0、或达到 100000 kcal）时，该条不计入、不编成 0；其余合法值仍相加。
- 不把训练从日活动能量里拆出，也不做活动/训练二选一或猜测扣减。Soma 不向 Apple 健康写回训练或活动能量；但日活动 `activeEnergyBurned` 仍可能包含手表或其他 App 对同一场训练的计量。无可靠自动关联时不谎称已去重，并在说明中保留这一重复可能。
- 明细必须能加总：静息、基准额外消耗、活动消耗、训练消耗。周月年展示日均四项，口径与日页相同。
- 已写入磁盘的能量依据必须仍能读取。校准评审里的 `presentedTotal` 使用 `EnergyInputCoding`（`JSONEncoder` + `sortedKeys`）的真实线格式：关联值是 `{"_0": n}` 或无标签数组，而不是手写的纯 Double。旧的 `recordedTraining` / `disaggregated` 按既定规则迁到新四项；当前版本写出的 `selected` / `absent` 必须能再读回。不得因这一解码失败把进展日页整页替换成版本不兼容提示。非法或边界训练数值不得让解码抛错而空白整页。总量公式本身不变。

## 数据与隐私

不新增持久模型、远程数据流或健康读取类型，不修改健康授权，也不为查重读取用户个人健康库。仍不写回 Apple 健康。

## 明确不在范围

- 为模糊重叠猜测扣减，或让用户在活动消耗与训练消耗中二选一。
- 改变残差系数提供方，或把 MET 毛消耗改写成净活动能量后再加入（那会与训练列表数字不一致）。
- 修改健康账户授权、写回 HealthKit，或把真实个人健康数据写入测试、日志或 Issue。
- TestFlight 或 App Store 分发。

## 验收

- 有日活动读数时，总量等于旧公式再加训练列表汇总；训练消耗在详情中独立可见，并与列表合法估算之和一致。
- 无训练时训练消耗为 0，活动消耗规则不变。无日活动读数时不编造活动，训练仍按列表口径加入。
- 新增、编辑、删除训练后，日页总量、明细、推荐/剩余摄入与周期汇总使用同一结果。
- 非法或空的单条估算不破坏其余合法值，也不把缺失写成 0。
- 说明不声称已与日活动能量去重。
- 用 `EnergyInputCoding` 编码的历史 `presentedTotal`（含 `recordedTraining` / `disaggregated` 关联值字典）以及当前四项编码，都能在进展加载路径解码；合成旧格式不得触发整页「与当前版本不兼容」。

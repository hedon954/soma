# PRD 015：对话启动计划带练

- 状态：已实现，待真机验收
- 日期：2026-08-04
- 修订自：[PRD 010](010-exercise-library-plans-guided-training.md) 的训练计划启动入口
- 后续修订：暂无
- 上游依据：[ADR 0040](../adr/0040-agent-guided-workout-launch.md)

## 用户结果

用户可以在教练对话中列出、查看、创建、调整、归档或永久删除训练计划，并说“开始基础力量训练”，无需
切换到进展页寻找计划。Agent 先读取可执行计划，再以稳定计划 ID 在本机启动带练；带练打开后仍由确定性
本地状态机负责组、休息、录像和完成。

## 产品规则

- `list_training_programs` 只返回当前数据空间未归档、具有当前模板的计划 ID、名称、目标与模板摘要。
- `get_training_program` 返回指定计划当前模板的动作顺序与处方；创建、版本化更新和归档继续使用既有固定 Tool。
- `delete_training_program` 只有在用户明确要求永久删除时可调用，删除计划和模板但不删除已开始的 Session
  快照或训练历史。
- 只有用户在当前消息明确要求开始、执行或带练某个计划时，Agent 才能调用 `start_guided_workout`。
- 启动前 Agent 必须先查询计划，且只使用返回的 `program_id`；找不到或不可执行时给出可理解失败结果。
- 启动创建新的不可变 `WorkoutSession` 快照并立即打开既有带练界面；默认关闭自动录像。
- 用户明确选择时，启动可选“每动作录一组”或“每组都录”；逐组和相机控制不向模型开放。
- 工具结果和聊天回答只说明已开始的计划，不暴露媒体路径、数据库内部信息或其他计划内容。

## 验收

- 对话查询只展示当前空间可执行计划，包含稳定 ID 供后续 Tool 使用。
- “开始某计划带练”创建一次 Session、打开带练，并保留当前计划的不可变快照。
- 默认启动不占用相机；明确录像策略与 GUI 启动保持同一语义。
- 无效、归档或没有模板的计划不创建 Session，并返回可恢复提示。
- 同一 Turn 的重复启动由现有 Tool 回执幂等，不创建两个 Session。
- 永久删除不会删除历史 Session、Performance、Set、录像或复盘。

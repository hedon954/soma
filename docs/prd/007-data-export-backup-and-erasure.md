# PRD 007：数据导出、自动备份与主动清除

- 状态：已采纳
- 日期：2026-07-30
- 修订自：[PRD 004](004-soma-current-product.md)
- 后续修订：[PRD 011](011-durable-agent-jobs-remote-continuity.md) 增加远程临时数据删除边界
- 关联决策：[ADR 0021](../adr/0021-portable-export-encrypted-backup-and-erasure.md)

## 背景

Soma 是无账户、本地优先的私人身体智能。数据库和原始媒体留在 App 沙盒可以降低默认隐私
风险，但也意味着用户卸载 App 后会失去数据。仅提供一个需要主动点击的“备份”按钮，无法
覆盖忘记备份、手机损坏或卸载前没有准备的真实场景；仅提供机器备份，也不能满足用户离开
Soma 后继续持有并阅读自己记录的需求。

“数据与备份”因此提供三个职责清晰的能力：

1. **导出**：生成不依赖 Soma 的开放目录，供长期阅读、迁移和自行整理；
2. **备份与恢复**：生成可完整恢复 Soma 个人空间的加密机器快照；
3. **清除数据**：主动删除当前设备上的个人业务数据与私有媒体。

## 用户结果

### 导出

- 用户选择系统“文件”中的一个目标文件夹后，Soma 新建一次带时间戳的导出目录。
- 饮食和训练记录按本地日历组织为 `年/月/日`，每条记录拥有独立目录。
- 每条记录包含：
  - `原始记录.txt`：原始用户文字、记录备注和可读分析摘要；
  - `分析结果.json`：稳定记录 ID、时间、结构化字段、来源和关联 Agent 结果；
  - `媒体/`：按原始顺序复制的图片和视频。
- 根目录包含 `manifest.json` 和 `说明.txt`，说明导出版本、生成时间、时区、记录数和结构。
- 没有可靠值的字段保持缺失或 `null`，不为了导出完整而补造事实。
- 单个媒体缺失时，导出继续完成，在 manifest 中列明缺失项；数据库读取或目标目录写入失败
  时不留下伪装成完整导出的目录。
- 导出只覆盖饮食与训练记录，不包含 API Key、开发者日志、内部幂等回执或演示数据。

### 备份与恢复

- 用户首次选择外部目录并设置备份密码后，Soma 立即创建第一份完整备份。
- 配置完成后，个人数据发生变化且 App 进入后台时尝试更新备份；设置页同时提供“立即备份”。
- 备份覆盖整个个人数据空间：个人资料、身体记录、饮食、训练、健身房、聊天 Session、
  消息、位置快照、Agent Trace、幂等回执、外部同步游标和所有被引用媒体。
- 备份不包含演示数据、AI API Key、系统相册原件、Apple 健康源数据或天气响应。
- 每份备份是独立、版本化、加密且带完整性校验的快照。新快照全部写入成功前保留上一份；
  自动备份失败不得破坏最后一份可恢复备份。
- 设置页展示最后成功时间和最近失败原因。外部目录不可用、设备锁定、后台时间不足或文件
  Provider 失败时保留本地数据并在下次进入后台重试。
- 恢复前先完整解密、校验版本、JSON 和媒体；密码错误、文件损坏或版本不支持时不改变当前
  数据。
- 恢复采用“替换个人空间”语义，并在执行前进行二次确认；演示空间和 API Key 不受影响。
- App 被卸载后，用户重新安装并选择备份目录，输入原密码即可恢复；不依赖仍然存在的
  Keychain 或书签。

### 清除数据

- 用户可以在设置中主动清除个人数据。
- 清除范围包含个人 SwiftData 空间和仅由个人空间引用的沙盒媒体；演示数据、AI 服务配置、
  API Key、系统相册和 Apple 健康源数据不删除。
- 如果同一沙盒媒体仍被演示空间引用，不删除该文件。
- 清除前必须明确显示范围并要求 destructive 二次确认。
- 清除成功后断开自动备份配置，但不删除外部目录中的已有备份，避免下一次后台备份把最后
  一份快照替换为空数据。
- 清除后 App 回到可继续使用的空个人空间，并建立新的对话 Session。

## 信息架构

设置页“更多”增加“数据与备份”，页面分为三组：

1. **导出数据**：说明开放目录用途，提供“导出饮食与训练”；
2. **备份与恢复**：显示状态、目标位置、最后成功时间，提供设置/更换目录、立即备份、
   恢复备份和停止自动备份；
3. **清除数据**：说明不会删除的外部数据，提供红色“清除个人数据”。

选择目录、恢复目录和密码输入均使用系统或原生控件。页面不展示加密密钥、数据库路径、
书签内容或内部 schema 实现。

## 隐私与安全

- 导出是用户明确发起的明文副本。开始前说明目标文件夹中的其他 App、共享成员或云盘服务
  可能访问内容。
- 备份中的 JSON 和媒体全部使用带认证的加密；密码和派生密钥不得写入 UserDefaults、
  日志、文档或 Git。
- 为后台自动备份缓存的派生密钥只存入 ThisDeviceOnly Keychain；卸载后的恢复仍要求原密码。
- 文件访问使用系统文件选择器授予的安全作用域，并在每次读写后释放。
- 文件名不得包含用户原始文字；目录名使用时间、记录类型和稳定 ID，降低旁路泄露。
- 失败信息只描述阶段和恢复建议，不输出健康内容、坐标、路径书签、密钥或媒体内容。

## 明确不在当前范围

- 账户、跨设备业务数据实时同步或云端身体数据库；[PRD 011](011-durable-agent-jobs-remote-continuity.md)
  的临时 Agent Job 服务不属于备份或长期同步；
- 自动上传到固定第三方云盘 API；
- 增量备份、备份历史浏览、选择性恢复或合并恢复；
- 导出身体记录、完整聊天记录或开发者 Trace；
- 把导出目录重新导入 Soma；
- 删除系统相册原件、Apple 健康样本、外部导出或外部备份。

## 验收

- 两天内的饮食和训练按本地 `年/月/日` 写入正确目录，文字、JSON 和有序混合媒体可在
  “文件”中独立打开。
- 缺少媒体时导出完成并在 manifest 标记；导出目录不包含 API Key、Trace 或演示记录。
- 设置备份后立即生成可校验加密快照；明文搜索找不到用户文字或媒体内容。
- App 进入后台后能生成新快照，失败时上一份仍可恢复，设置页可见失败状态。
- 正确密码可以替换恢复完整个人空间及媒体；错误密码、篡改媒体和不支持版本均不改变当前
  数据。
- 清除只删除个人空间和未共享媒体，保留演示空间、API Key、系统相册、Apple 健康和外部
  备份；自动备份配置同时断开。
- Dynamic Type、VoiceOver、浅色/深色、空数据、无目录权限和长错误信息可用。
- `make verify` 通过，并在真机完成文件夹选择、后台自动备份、卸载重装恢复和主动清除手工
  验收。

# PRD 069：训练课程与训练计划分开命名

## 背景

现在叫做训练计划的东西，是一堂课：若干动作和各自的组数、次数或时长、重量、间歇。
它没有开始日，也没有周期里的每一天。接下来要做的训练计划，是跟日期绑在一起的一轮安排。
两个东西继续共用一个名字，后面的排期、补做和停练都无法说清。

## 用户结果

训练页、课程编辑、带练提示、动作详情里的「本课程目标」，以及教练对用户说出的名称，都把
这一堂动作处方叫做训练课程。归档、删除、新建和空态用的也是课程。

工具的英文名称和参数名不变。已经保存在本机、被用户改过的 Skill 正文不覆盖。

## 产品规则

- 训练课程是动作和组参数的当前处方，对应现有 `TrainingProgram`。
- 训练计划这个名字留给按开始日和周期把课程或休息排到每一天的能力，本版不提供该能力。
- 内置课程 Skill 的默认说明改为编写课程，不在课程里规定每周哪一天练。

## 数据与隐私

不新增字段、不迁移数据、不改 Tool Schema。只改用户和模型看见的中文名称。

## 明确不在范围

- 不新建训练计划模型，不排日期。
- 不重命名 Swift 类型、Tool 名或 `program_id`。

## 验收

训练页空态、新建页和删除确认写的是训练课程。工具描述里的创建、更新、归档、删除也写训练课程，
工具名仍是 `create_program` 等现有名称。执行 `make check`。

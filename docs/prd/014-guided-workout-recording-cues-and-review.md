## 背景

当前自动录像只有开关，固定为每动作一段；相机在开始页提前启动，即使某组不会录像也持续显示。
录像真正开始与否没有独立状态，停止时又重新按策略推断，导致首组录制失败、手动录制无法接入。

语音只覆盖“准备第 N 组”，没有倒计时数字、正式开组、后续组和完成提醒。最后一组结束后的反馈
只有一句文本，训练历史也不能直接左滑删除。这些缺口让带练看起来像一组孤立页面，而不是持续
陪伴用户完成训练的教练。

## 用户结果

1. 用户显式开启自动录像后，可以选择“每个动作录一组”或“每一组都录”。
2. 自动录像关闭或当前组不在自动目标内时，每一组都能手动开始录像。
3. 只有系统确认录像已经开始时才显示取景器；其余时间不初始化相机。
4. 自动目标组在倒计时结束后可靠发起录像，失败时展示原因并允许当前组重试。
5. 紧凑小窗没有上下黑边；放大完整取景仍能解释保存画幅。
6. 每一组都拥有准备、3/2/1、开始和完成/休息语音，换动作与训练完成也会自动播报。
7. 最后一组完成后展示训练时长、动作数、完成/跳过组、训练容量、录像数和动作明细。
8. 计划训练历史支持从右向左滑出删除按钮，并确定性清理关联事实与私有录像。

## 产品规则

### 开始训练

- 开始页保留语音提示和“自动录像”显式开关。
- 开启自动录像后显示策略选择：
  - 默认“每个动作录一组”：首组不是热身时录第 1 组；首组是热身时录首个工作组；
  - “每一组都录”：包括热身组在内的每一组都自动录像。
- 开始页不展示相机校准、不请求权限、不启动 Capture Session。
- 文案明确说明：只有进入需要录像的组时才使用前置相机，麦克风关闭，视频留在 Soma。

### 本组执行与录像

- 自动目标组在组前倒计时归零后立即进入执行状态，并异步请求录像。
- 系统回调确认写入已经开始后，UI 才显示“正在录制”、相机小窗和放大入口。
- 自动录像关闭，或当前组不是自动目标时，执行页显示“录制本组”；点击后从当前时刻开始录像。
- 录像启动中暂时禁用重复开始和完成，展示紧凑进度；成功后恢复完成操作。
- 用户确认完成、跳过、暂停、提前结束或 App 进入后台时停止或取消当前组录像。
- 每个成功文件绑定到当前 `WorkoutSet`；动作复盘能查看该动作的多段 Set 录像。
- 失败必须显示用户可理解的原因与“重试录制”入口；训练事实继续可完成。

### 取景器

- 没有实际录像时不渲染取景器，主视觉保持动作示意。
- 紧凑小窗使用比例填满，允许少量裁切以消除无意义黑边；窗口本身不增加装饰黑框。
- 放大“完整取景”继续完整适配，展示保存文件的完整边界；紧凑小窗不能被描述为完整画幅。
- 紧凑与放大继续共享同一 Session、Output 和 Preview Layer，切换不停止文件。

### 语音指导

- 语音开启时，确定性事件自动生成以下提示：
  - 进入动作：“接下来，动作名称”；
  - 进入组：“准备第 N 组”；
  - 组前倒计时：“3、2、1”；
  - 组开始：“开始第 N 组”；
  - 组完成：“第 N 组完成，休息 X 秒”或“动作完成”；
  - 休息最后 3 秒：“3、2、1”；
  - 下一动作与训练完成。
- 同一阶段和同一秒只播报一次；阶段变化时取消已经过期的队列，不让上一组语音拖到下一组。
- 关闭语音后不创建 utterance；暂停、恢复和手动跳过保持状态可解释。

### 完成反馈

- 最后一组确认后进入独立本地复盘页，不立即消失。
- 复盘页展示可确定的训练时长、动作数、完成组、跳过组、外部重量容量、录像数量和逐动作完成数。
- 缺失重量时不伪造容量；自重训练可以显示完成组与次数，不把体重当作外部重量。
- 主操作为“完成并返回”；次操作允许把当前 Session 带入教练继续总结，但不会重复创建训练事实。
- 完成页不自动调用模型或上传录像。

### 历史删除

- “训练历史”列表行支持尾随左滑删除，遵循系统 destructive 样式并允许全滑。
- 删除范围包括目标 Session、所属 Performance、Set、PerformanceAnalysis，以及 Soma 私有目录中
  只属于该 Session 的录像。
- 删除不影响训练计划模板、动作定义、其他 Session、系统相册或聊天原始媒体。
- 删除失败时保留列表项并显示错误；成功后列表即时消失。

## 空态、失败态与恢复

- 没有录像：不显示空黑窗，仅显示可用的“录制本组”。
- 权限拒绝：显示可到系统设置恢复的说明，本组和后续训练仍可完成。
- 启动或写入失败：显示具体错误，清理临时文件，允许本组重试。
- App 后台或相机中断：取消当前未完成录像，Set 保持执行/确认状态，返回后由用户决定重录。
- 没有完整重量证据：总结隐藏容量或标为未形成，不显示 `0 kg` 冒充有效数据。

## 隐私与可访问性

- 相机按 Set 最小化使用；不开录像不申请权限、不占用绿色隐私指示。
- 麦克风不加入 Capture Session；所有录制保存在 App 私有目录。
- 录像、错误、开始/停止按钮提供 VoiceOver 标签；语音不是唯一状态提示，屏幕与触觉仍同步。
- 复盘页支持 Dynamic Type；长动作名和多个统计项可换行，不依赖颜色表达完成或失败。

## 验收

1. 自动录像关闭时，进入任意组不会出现绿色相机指示或取景器；点击“录制本组”后才出现。
2. “每个动作录一组”只录每动作首个目标工作组；“每一组都录”会为每个完成 Set 保存独立视频。
3. 自动首组在系统 `didStartRecordingTo` 后显示红点，完成后 Set 拥有可播放路径；失败可见且可重试。
4. 紧凑小窗无上下黑边，放大态能看到完整画幅，来回切换文件不中断。
5. 第一组和后续组均按顺序播报准备、3/2/1 与开始；休息和训练完成有对应语音。
6. 最后一组完成后停留在本地总结页，展示真实统计和动作明细，不自动调用 AI。
7. 训练历史左滑删除后，Session 关联模型和 Soma 私有录像均被清理，其他计划与历史不变。

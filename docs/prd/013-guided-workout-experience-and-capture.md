## 背景

现有计划创建器把所有字段常驻展开，动作选择缺少示意图和最近值快捷入口；现有带练页同时
展示固定高度相机、阶段文本和多次确认，视觉重心分散，完成一组需要“完成”与“保存”两次
点击。相机预览使用裁切填充且 iPhone 只允许竖屏，用户看到的取景范围与最终视频可能不同。

这些问题直接影响一个高频闭环：用户需要在器械旁快速确认下一步，而不是阅读表单或调试相机。

## 用户结果

1. 用户可以在聊天生成计划，也可以在 GUI 中通过动作图片、搜索和排序快速组合计划。
2. 用户主动点击“使用上次”后，最近完成训练中明确的组数、次数、重量和间歇进入计划草稿。
3. 计划启动后，动作示范、本组目标、组进度、相机取景和完成按钮在一屏内完成。
4. 目标录像组开始时自动放大相机；收起、重新放大和旋转设备不打断当前录像。
5. 横屏和竖屏预览都完整展示最终会被保存的画幅，不用裁切冒充最终结果。
6. 完成一组只需一次确认；休息、暂停、恢复、跳过和异常退出仍可解释并恢复。
7. 倒计时归零先立即进入本组；相机准备或启动不能阻塞训练状态和主操作。

## 产品规则

### 计划 GUI

- 入口仍在“进展 → 训练计划”，有活动 Session 时优先展示继续训练。
- 动作选择器只读取当前空间 active `ExerciseDefinition`，左侧显示动作示意图。
- 已选动作默认显示名称和处方摘要，点按进入编辑面板；支持排序、删除和重复添加。
- “使用上次”是显式操作：
  - 最近完成记录决定来源；
  - 完成组数可以复用；
  - 次数、重量和间歇只有在该记录中拥有一个明确值时才复用；
  - 缺失或不一致保持空，不猜测；
  - 不调用模型或网络。
- 保存继续创建不可变模板版本；已开始 Session 使用原快照。

### 开始前

- 开始页只保留训练就绪结果、语音提示和自动录像开关。
- 开启录像后展示一次 capture-exact 校准页，用户确认全身进入最终画幅后开始。
- 相机权限拒绝或不可用时允许继续训练，并明确本次不录像。

### 紧凑带练

- 当前动作示意或本地已授权指导视频是主视觉；外部链接不自动播放。
- 相机小窗展示完整画幅、录制状态和放大入口。
- 页面只保留当前动作、目标、组进度、一条教练提示和一个主按钮。
- 主按钮文案包含本次将保存的实际值；点按即停止录像、保存 Set 并进入下一阶段。
- 用户可以在完成前编辑实际次数和重量；空字段允许保持空。
- 替换、跳过、暂停和提前结束进入次级菜单。

### 放大录像

- 自动录像目标仍由 `firstSetIsWarmup` 决定第 1 或第 2 组。
- 录像成功开始时自动放大；失败时保持紧凑态并展示非阻塞错误。
- 用户可以在录制中收起或重新放大，不能因此重建 Capture Session 或停止文件输出。
- 紧凑、校准和放大态都优先把最大可用区域交给相机，不能用大面积装饰留白压缩取景。
- 竖屏把动作标题、组进度、提示、编辑和主按钮固定在底部；相机使用顶部栏与底部控制区之外的
  全部剩余高度。动作名称与本组目标合并为“动作名（重量、次数）”，不单独占用目标行。横屏
  使用大相机与窄控制栏分栏，相机至少占主要宽度。
- “正在录制”只表示文件输出状态，不能冒充取景画面已经可见；预览尚未渲染时显示连接态，失败时
  在取景表面说明原因并明确训练仍可继续。
- 横竖界面由当前 Scene 的实际尺寸决定，录像片段锁定的 Capture Geometry 不反向控制 UI 布局。
- 预览和文件共享完整画幅、方向和镜像；必要时留白，禁止裁切填满。
- 录像开始时锁定本段方向；停止后重新跟随设备摆放。

### 休息、恢复与完成

- 休息显示倒计时、下一组、增减 15 秒和跳过；目标结束时间可在重启后恢复。
- 休息中的本地通知和 Live Activity 只显示通用训练进度与时间。
- 暂停停止并丢弃未完成录像；恢复进行中 Set 时让用户选择已完成、重做或跳过。
- 完成页读取已逐组保存的事实，不再用“保存并结束”暗示此前尚未保存。
- AI 复盘和视频分析保持用户主动触发。

## 数据与隐私

- 最近容量、计划草稿、Session、Set 和视频默认只在当前本地数据空间。
- 新增恢复字段必须进入开放导出、加密备份、恢复和主动清除。
- 相机无音轨；视频不自动进入系统相册、不自动发送模型。
- Live Activity 不显示动作、重量、健康文本或媒体。
- 开启横屏只改变带练界面与录像，不改变其他业务页面的信息架构。

## 明确不在范围

- 抓取、下载或重新分发 Keep、YouTube 等第三方课程；
- 自动计次、人体识别、姿态实时评分或旁人检测；
- 自动为每个计划运行 AI 建议；
- 自动把非一致历史值压缩为看似统一的目标；
- 新增顶层训练 Tab、账户或服务器训练事实数据库。

## 验收

- 计划创建器通过图片选择动作，处方默认折叠，用户可显式应用最近明确值。
- 常规计划组从执行到休息只需一次完成操作，数据立即落盘。
- 目标组开始录像后自动放大；收起和重新放大不中断输出。
- 放大态首屏同时显示“动作名（重量、次数）”和完整组操作；底部控制区固定，相机自适应占满其余
  可用空间；预览失败不得静默显示黑色取景框。
- 倒计时归零后训练界面立即可操作；相机准备态、启动失败或编码等待不能冻结页面。
- 竖屏、横屏预览与保存视频的边界、方向、镜像一致，录制中旋转不改变当前片段。
- 权限拒绝、中断、后台、磁盘或热压力不破坏训练状态。
- 暂停恢复不自动把进行中组标记为完成。
- Live Activity 与通知不泄露动作、重量或媒体信息。
- VoiceOver、Dynamic Type、深浅色、长动作名称、安全区和键盘通过验收。
- `make check`、`make verify` 和文档双向生命周期门禁通过。

# 用户错误呈现清单

- 上游依据：[ADR 0132](../adr/0132-actionable-error-presentation.md)、[BUG 0064](../bugs/0064-raw-errors-without-recovery.md)

| 入口 | 原因来源与显示边界 | 恢复路径 |
| --- | --- | --- |
| 教练请求、旧失败卡、执行日志 | `AppErrorMessage` 与模型分类；旧文本仅显示时净化 | 重试、LLM 配置、更换输入；成功记录保留 |
| 远程任务和媒体上传 | 稳定服务分类；不回显响应体 | 等待后重试、重新发送、设置反馈；不引用不存在的远程设置 |
| 听写 | 本地权限和识别错误 | 系统权限、重试、继续键盘输入 |
| 带练、录像、替换动作 | 业务验证、相机原因与存储原因 | 修正目标、重新录像；训练可继续，部分证据保留 |
| 计划、动作、记录编辑 | `save` 上下文与具体字段验证 | 保留填写内容、修正后保存 |
| 进展、日记录、生活方式 | `load` 上下文与系统原因 | 返回后重开、重试读取 |
| 暂存与会话删除 | `delete` 上下文、远程取消结果 | 确认当前列表状态后重试；取消失败不先删本机 |
| 分享渲染、文件及相册写入 | 媒体/存储/权限分类 | 重试渲染、释放空间、系统相册权限 |
| 备份、恢复 | 数据归档错误及系统读写原因 | 完整备份、密码、重新选择目录、释放空间 |
| LLM 配置、辅助生成 | 授权、模型、地址、格式原因 | 检查配置，清空无效高级项或更换模型 |
| 设置反馈 | 服务配置、授权、网络原因 | 保留内容、改用 Wi-Fi、稍后重试 |
| 启动数据门禁 | 迁移/本地存储原因 | 重开或更新；展开/导出诊断并联系维护者 |

普通错误不呈现 JSON、内部 ID、原始英文异常或调用栈。已存在的显式诊断导出继续服务定位；
机器 Tool observation 保持结构化失败语义，不以 UI 文案替换协议。
新入口必须复用分类，且核对提示中的操作确实存在。自动化验证见 `AppErrorMessageTests`、
`WorkoutRecordingFailureDiagnosisTests`、Server 测试和呈现层静态门禁。

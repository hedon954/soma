# 训练记录与逻辑组

## 不可丢失的证据

`WorkoutSetEvidence` 的数组顺序和每个元素中的以下字段都属于事实：

- `logicalSetIndex`
- `side`
- `kind`
- `targetKind`
- `reps` 或 `durationSeconds`
- `externalWeightKG`
- `restSeconds`
- `recordedVideoPath`
- `recordedVideoKind`

聊天编辑、详情编辑和显示压缩都必须经 `WorkoutRecordDraft` / `WorkoutRecordEditorProjection` 往返。禁止用聚合的 `sets/reps/weight/duration/rest` 重新生成数组。

## 用户术语

- 次数/时长和侧别配置只读取 `ExerciseDefinition`；记录 evidence 不得覆盖动作定义。旧 evidence 只有另一目标槽位时，编辑投影可把同一已记录数值解释到定义槽位，但不能改写重量、间歇、顺序或录像。

- 字段类别叫“侧别”。
- `.none` 或无侧别证据显示“双侧同时”。
- 同一 `logicalSetIndex` 包含左、右 effort 时显示“左右各做”。
- 单独左或右显示“仅左”“仅右”。
- `targetKind` 只显示“次数”或“时长”。

不要显示“1 组、2 组、3 组”等组号标签。自然顺序和分段进度负责定位；校验错误和 VoiceOver 可以朗读序号来帮助定位。

## 压缩和编辑

- 聊天紧凑卡只保留一层动作卡表面：动作头下直接显示目标/侧别 chip、完成值、重量和 `×N`；不要再给每个逻辑组套第二层大卡。详情页继续使用标准密度。
- 完成行是一行可编辑文字：`60 秒 · 自重`，右侧 `×N`。一条记录里各组都相同时，组间歇写在同一行；组与组有差别时，组间歇放在相邻组块中间。左右各做时，换侧间歇仍在同一组卡片里左右两条记录中间；组数 `×N` 放在左右成对卡片的右侧垂直居中，不要只钉在左行。数字和间歇仍可点选编辑，不要做成胶囊。
- 连续逻辑组的侧别、类型、目标、次数/时长和重量相同即可压缩为一个块并显示 `×N`；间歇不参与相同判断。
- 修改压缩块时把可见字段批量应用到该 run 的各组，但保留每组原有 ID 顺序和录像元数据。
- 任一参与压缩的处方字段不同就分别显示，不要只因为组数多就合并。
- 左右 effort 在同一逻辑组卡片中保存；改单侧不能覆盖另一侧。
- 复制组复制处方/完成值但不复制录像证据；新增组使用下一个逻辑索引。

## 缺失、重量和间歇

本节描述实际训练记录。计划编辑器的组间歇与换侧间歇属于动作级配置，开始训练时再编译到逻辑组；
实际记录仍按逻辑组保留休息证据。

- 缺失值显示“—”，保存仍为 `nil`。Agent 新写入的外部重量与组间间歇未说明时落 0：0kg 显示“自重”，0 秒显示“间歇 0 秒”。
- 外部重量 0 显示“自重”；不要把 `nil` 当自重或 0。
- 确定的左右间歇放在左右行之间，组间歇放在组块之后。
- 动作最后一个逻辑组不显示或编辑组间歇；如果是左右各做，最后一组仍保留必要的换侧间歇。
- 压缩忽略间歇只影响显示 run，不得清空或覆盖各组原有 `restSeconds`。
- 历史数据不能区分时只写“间歇”，不要猜成“换侧间歇”或“组间歇”。
- 只读历史摘要复用同一逻辑组投影，连续相同事实显示为 `4×5次 29kg · 1×3次 29kg`；
  不展开“第 1 组…”文案，间歇不参与压缩，最后逻辑组的组后间歇不进入摘要。
- 容量只累加同时具有有效次数与外部重量的完成证据；自重与缺失值不补零。趋势必须显示真实记录日期，
  并在图外给出最近容量与较上次变化，不能只留一条无数值黑线。

## 编辑校验

- 次数范围为 1–1000，时长范围为 1–86400 秒，外部重量范围为 0–1000 kg，间歇范围为 0–3600 秒。
- 留空始终是合法的 `nil`；不要为了通过校验补默认数字。
- 越界字段在原位置使用系统红描边和一句范围提示，保存入口必须拒绝写入，但其他有效逻辑组和录像证据继续保留。
- 所有数字输入、确认、删除和组操作至少 44×44 pt，并提供能说明动作和结果的 VoiceOver label/value。

## 带练

- 进度按动作和逻辑组分段；左右各做仍是一个逻辑组，可以用半段表达一侧完成。
- 页面不显示组号，VoiceOver 可说明已完成/部分/总组数。
- 相机失败、暂停、前后台和重试都不能回滚已经完成的 effort 或丢失有效录像证据。

## 分享海报明细

按 ADR 0119，分享投影合并全部同重量与次数/时长的组（含非连续同值），忽略间歇、录像和类型元数据，保留左右不同完成事实；动作是外卡，每个合并项为内卡。不改变编辑器与训练历史的有序证据。

# 分享海报：目的、内容与改版

## 这张图是为了什么

不是复盘页的缩小版，也不是完整训练日志导出。它是**可发出去的训练瞬间**：

1. **一眼看懂练了什么**（受力图是主角）
2. **三个可信数字**证明「练了、有量、有时长」
3. **动作清单点到为止**，让人知道做了哪些动作，而不是逐组记账
4. **Soma 品牌轻标识**，不夹带隐私/合规说明

隐私文案（「不含照片、视频或位置」）只留在分享 sheet 的 UI 说明里，**不要印在海报上**——那是产品自我解释，不是分享内容。

仍遵守 [ADR 0044](docs/adr/0044-programmatic-muscle-map-and-training-share-poster.md)：无头像、无二维码、无照片/视频/位置/训练天数。

## 应该包含什么（信息层级）

| 层级     | 内容                                               | 作用                           |
| -------- | -------------------------------------------------- | ------------------------------ |
| 身份     | 日期 + 计划名（无计划则用前 1–2 个点亮肌群）       | 这是哪一次                     |
| 视觉主角 | 正背面受力图（海报内可关引线标签，靠点亮区域说话） | 练了哪些部位                   |
| 焦点补充 | 点亮肌群短标签（最多 3 个 chip）                   | 填满顶部语义空白，替代散落引线 |
| 三个数字 | 有效容量 / 完成组 / 总耗时                         | 可扫读的结果                   |
| 动作摘要 | 每行动作名 + **一行**负荷摘要                      | 有内容但不杂                   |
| 品牌     | `Soma` + 「本地训练记录」                          | 克制收尾                       |

**动作摘要规则（替代当前两组一排的杂乱格子）：**

- 各组负荷相同：`5组 · 自重 × 5` / `2组 · 30kg × 5`
- 各组不同：压成一行 `30kg×5 · 35kg×5 · 40kg×3`（超过约 4 组时截断为前几组 + `等`）
- 无重量（自重/未填）：显示 `自重 × N` 或 `× N`，禁止再出现 `— × 5`

## 怎样才美观（针对当前截图）

当前问题：

- 日期/标题漂在卡片外 → 顶部大片留白
- 受力图引线标签在小图上抢戏
- 底部逐组双列像未排版的草稿
- 海报脚注像说明书

改版构图（单列、一张图）：

```text
┌─────────────────────────────┐
│ 薄荷渐变底                   │
│ ┌─ 主卡片 ───────────────┐ │
│ │ 日期                      │ │
│ │ 计划名 / 肌群焦点（大）   │ │
│ │ [股四头肌] [背阔肌] …     │ │
│ │                           │ │
│ │  人体图(更大)   300 kg    │ │
│ │  正/背无引线     7 组     │ │
│ │                 6分10秒   │ │
│ └───────────────────────────┘ │
│ ┌─ 明细卡片 ─────────────┐ │
│ │ 引体向上                 │ │
│ │ 5组 · 自重 × 5           │ │
│ │ ─────────────────────   │ │
│ │ 杠铃深蹲                 │ │
│ │ 2组 · 30kg × 5           │ │
│ └───────────────────────────┘ │
│ Soma              本地训练记录 │
└─────────────────────────────┘
```

视觉原则：

- **一块主视觉卡**吃掉标题区，消灭顶部空洞
- 人体图加大、关标签；肌群用 chip 表达（比引线更整齐）
- 明细卡每动作两行（名 + 摘要），行间细分割线，不再网格堆数字
- 数字用 ink 主色，Soma tint 只留给品牌字，避免满屏绿字抢戏
- 外圈 padding 收紧（约 14–16），卡片内间距统一

## 实现落点

主要改 [`Soma/Views/WorkoutShareViews.swift`](Soma/Views/WorkoutShareViews.swift)：

1. `ExerciseLine` 增加预计算的 `summaryText`（builder 内按上面规则生成）
2. `WorkoutSharePosterView` 重排：header 并入 summary 卡；`MuscleMapView(..., showsLabels: false)` 并略增 height；明细改为 name + summary；footer 去掉隐私第二行
3. Builder 里把 `weight == nil` 与 `0` 都按自重/无外负荷处理，消灭 `—`
4. 分享 sheet 文案保留隐私说明即可，海报本身不再出现

不改 ADR/PRD 边界；`CHANGELOG` 补一句分享海报信息架构调整。

## 验收

- 同一会话重新打开分享：顶部不再大块空白；引体显示「5组 · 自重 × 5」类摘要而非 `— × 5` 网格
- 海报无「不含照片…」字样；sheet 下仍有说明
- 长按/保存到相册/系统分享仍可用
- 装到真机目视确认
